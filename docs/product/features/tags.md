# Tags（タグ）

エントリの活動分類。Dayoptにおけるタスク管理の代替（タスクリストは持たない）。

## 現在の振る舞い

- コロン(`:`)区切りで最大2階層の分類を表現する（例: `仕事:開発`, `学習:英語`）
- 各タグにカラー（10色パレット）とアイコンを設定できる
- 1エントリ1タグ（複数タグの付与はしない）
- タグ削除時は影響を受けるエントリの扱いを確認するダイアログを挟む
