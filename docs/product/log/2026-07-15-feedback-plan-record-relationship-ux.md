# Plan / Record の移動導線と関係表示

Plan から Record へ記録する操作の配置と、両者の関係を詳細画面でどう見せるかについてのフィードバック。

---

## 原文

> では次ね。planをrecordに移動させる方法を検討したい。どこにボタンを用意するか。ID表示をどのように設計するか

## 文脈

Timeblock 詳細の自動保存、コピー、Plan のワンタップ記録を整えた後、Plan / Record の関係を通常 UI で理解・移動できる設計を検討した。

## 解釈

- ワンタップ記録は Plan 詳細の操作として置き、保存中の編集を確定してから Record を作る
- raw UUID は通常 UI の識別情報にせず、タグと日時で関係を表す
- Plan から関連 Record、Record から元 Plan の双方へ同じ詳細パネル内で移動できるようにする

## 対応

- Plan 詳細に「関連する記録」の件数、合計時間、一覧を表示する
- Record 詳細に「元の予定」を表示する
- 関係行の選択とワンタップ記録成功後に、同じ Inspector の対象を相手へ切り替える
- 詳細仕様を `docs/product/specs/plan-record.md` に反映する
