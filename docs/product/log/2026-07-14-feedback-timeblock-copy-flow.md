# Timeblock のコピー導線を全体で完成させたい

## 原文

> ok.あとはどこにコピーボタンを置いてコピーした場合うまくリレーションさせるかかな。いい案ある？

> なるほど？ちなみに現状詳細は削除と振り返りのみなのでその辺踏まえて全体的に完成させて

## 文脈

Plan の「そのまま記録」は Record と ID で関連付ける一方、通常のコピーをどこへ置き、関連をどう扱うかを検討した。詳細 Inspector のメニューは現状、削除と振り返りが中心になっている。

## 対応方針

- コピーは詳細 Inspector とカード右クリックの共通 `…` メニューへ追加する
- コピーした Timeblock は元の種別を維持した独立複製とし、`id` / `plan_id` は引き継がない
- Plan と Record の関連付けは「そのまま記録」などの明示的な記録導線だけが担う
- 貼り付け可能な時間帯でない場合は種別を暗黙変換せず、その理由を表示する
