# User フィードバック: カレンダーグリッドの縦余白とヘッダー入口の重複

カレンダーのコンパクト表示で縦の viewport が使い切られていない点と、ヘッダーの「アナリティクス」「差分」2 トグルが冗長に見える点、の 2 件。原文のまま記録する。

---

## 原文

> サービスを使っていての違和感を共有しておきます。まず時間の部分だけど、コンパクト表示だと縦の画面幅がすべて使われないのは直したい。100％のなかでサイズ替えができるのがいいかな。あとヘッダーのアナリティクスと差分のところ。ここやっぱり2つじゃなくて1つでとういつでもいいきがするんだけどどうだろうか。

## 文脈

2026-08-18、指揮台への口頭フィードバックとして受領。時間グリッドの各スロット高さが固定 px（`HOUR_HEIGHT_DENSITIES`）で、viewport 高を一切参照せずに `overflow-y-auto` でスクロール吸収していたため、縦に余っても使い切らず、密度プリセットの切替も「100% の中でのサイズ替え」にはなっていなかった。ヘッダー側は「振り返り（アナリティクス）」と「差分」の 2 トグルが別々に並び、パネルの入口が分かれていた。

## 解釈

- 時間グリッド: 密度プリセットの意味を固定 px から「viewport にフィットする比率」へ再定義する要望
- ヘッダー: 2 つの入口を 1 つに統合し、パネル内で切り替える形が自然という要望

## 対応

- [#2148](https://github.com/Dayopt/dayopt/issues/2148) — 時間グリッドの viewport フィット（密度プリセットをコンテナ実測高に対する倍率へ再定義）
- [#2149](https://github.com/Dayopt/dayopt/issues/2149) — ヘッダーの review/diff 入口統合（段階統合 Phase 1。データ取得経路の統合は Phase 2 送り）
- 両 issue を束ねて [PR #2161](https://github.com/Dayopt/dayopt/pull/2161) で同日出荷済み
