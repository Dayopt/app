# 価格戦略

Dayoptの Free/Pro 境界線と価格設定に関する分析ドキュメント。
3つのAIエージェント（Strategist / Devil's Advocate / Customer）による多角的分析に基づく。

> プロダクトの最上位コンセプトは [`docs/product/concept.md`](../product/concept.md) を参照（2026-07-02 策定）。**in-app AI 機能（AI振り返り）は作らない方針**のため、以下の表・分析から AI 振り返り関連の記述を除去済み。AI 価値は MCP/API 経由の外部 AI 連携として提供する。Free/Pro の詳細な線引きは [`v1-definition.md`](../product/v1-definition.md) の未決事項であり、本ドキュメントは今後見直す。

## 現在の価格設定

|                                   | Free ($0) | Pro ($5/月) |
| --------------------------------- | --------- | ----------- |
| タイムボクシング & 時間記録       | ✅        | ✅          |
| 基本分析（2指標、精度スコア含む） | ✅        | ✅          |
| タグ                              | 5個まで   | 無制限      |
| 全8指標 + チャートビュー          | -         | ✅          |
| MCP / APIアクセス                 | -         | ✅          |
| データエクスポート（CSV/JSON）    | -         | ✅          |

> 年払い: $48/年（20% OFF、月あたり$4）

### 設計原則

- **Freeで「タイムボクシングの基本体験」を完全に提供する**
- **Proで「自己改善のインサイト層」+ 「API/データ連携」をゲーティングする**
- ユーザーが「もっと自分の時間の使い方を理解したい」と思った瞬間がコンバージョンポイント

## $5/月の妥当性

### 競合比較

| プロダクト      | 無料枠       | 有料      | ポジション                     |
| --------------- | ------------ | --------- | ------------------------------ |
| Google Calendar | 全機能無料   | -         | カレンダーのみ                 |
| Toggl Track     | 基本無料     | $9/月     | 時間記録のみ                   |
| Notion          | 基本無料     | $8/月     | ノート+タスク                  |
| Fantastical     | 制限付き無料 | $4.75/月  | カレンダー+タスク              |
| Sunsama         | なし         | $16/月    | タイムボクシング+統合          |
| **Dayopt**      | **あり**     | **$5/月** | **タイムボクシング+記録+分析** |

### 判定

- Sunsama的な機能セットをFantastical的な価格帯で提供するポジション
- $5はSaaSの「衝動購買の閾値」以下で、解約検討対象になりにくい
- SaaSは `.99` を使わない。$5のラウンドナンバーが正解
- 「コーヒー1杯以下」のフレーミングが成立する

## Strategist分析

### 推奨ビジネスモデル: Freemium

| 層   | 料金                  | 対象                         |
| ---- | --------------------- | ---------------------------- |
| Free | $0                    | タイムボクシングを試したい人 |
| Pro  | $5/月（年払い$48/年） | パワーユーザー               |

### マネタイズ優先順位

1. **Phase 1: 決済基盤 + 最小ゲーティング**（最優先）
   - Stripe Checkout + Customer Portal + Webhook
   - `user_settings` に `subscription_tier` 追加
   - tRPC に `proProcedure` ミドルウェア追加
   - 分析指標の MetricCard にブラー表示

2. **Phase 2: Proの質的差別化**
   - 週次/月次自動レポート生成（ルールベース統計。in-app AI ではない）
   - CSV/JSONエクスポート
   - チャートビューの拡充

3. **Phase 3: 成長施策**
   - 年間プラン（$48/年、20% OFF）

### LTV最大化戦略

- **習慣定着**: 「見積もり精度が4週間前より上がっている」等、過去の自分との事実比較で進捗感を作る（ストリーク・バッジ等の gamification は [concept.md §4-6](../product/concept.md) で永久禁止）
- **週次サマリーメール**: stats featureの8指標を活用
- **アップセル**: 分析画面でPro限定指標を「ブラー表示」

### 収益シミュレーション（保守的）

| 時期     | MAU    | 有料転換率 | 有料ユーザー | MRR    |
| -------- | ------ | ---------- | ------------ | ------ |
| 12ヶ月後 | 5,000  | 3%         | 150          | $750   |
| 24ヶ月後 | 15,000 | 5%         | 750          | $4,500 |

## Devil's Advocate分析

### 致命的問題

#### 1. Free tierが太りすぎ（対策済み）

旧構成では分析8指標・クロノタイプがすべて無料だった。
→ 新構成で Free を「基本分析2指標」に絞り、Pro にインサイト層を集約。（旧: AI月30回無料 → in-app AI 機能自体を廃止したため本論点は解消）

#### 2. Googleカレンダー同期の不在

「一体化」がUSPなのに最大カレンダーと繋がらない。
ユーザーに二重管理を強いる時点で、プロダクトの約束を果たしていない。

> Gcal連携の位置づけは未決定。Proの強力なコンバージョントリガーになりうる。

#### 3. Pro特典が量的制限の解除だけ（対策済み）

旧構成の「無制限タスク/タグ + 優先サポート」は消極的動機だった。
→ 新構成で「全8指標 + チャート + API + エクスポート」に質的差別化。

### 離脱シナリオ（Churn Triggers）

| タイミング | トリガー                  | 対策                   |
| ---------- | ------------------------- | ---------------------- |
| Day 3      | 「記録するの面倒」        | 自動記録の強化         |
| Week 2     | 「分析見たけど So what?」 | 日次マイクロインサイト |
| Month 2    | 「Gcalに戻せない」        | データエクスポート     |

### 抜け穴

| 抜け穴                                       | 対策                               |
| -------------------------------------------- | ---------------------------------- |
| タスク数制限がサーバーサイドで未エンフォース | tRPCミドルウェアでカウントチェック |
| Gmail+エイリアスで無限アカウント             | IP/デバイスベースのレート制限      |

## 価格帯再分析（Round 2）

Round 1 の結果を受けて、「$5は本当に正しいか」を $3/$5/$8/$10 の4価格帯で深掘り分析。

### 損益分岐点（BEP）

目標年収500万円（$33,000/年 = $2,750/月）、インフラ固定費 ~$47/月として算出。

| 価格 | 変動費/人 | 粗利/人 | BEP（固定費のみ） | BEP（生活費込み） |
| ---- | --------- | ------- | ----------------- | ----------------- |
| $3   | $0.15     | $2.85   | 17人              | **981人**         |
| $5   | $0.15     | $4.85   | 10人              | **577人**         |
| $8   | $0.20     | $7.80   | 7人               | **359人**         |
| $10  | $0.20     | $9.80   | 5人               | **286人**         |

> ~~AI原価: Haiku ~$0.001/req、Sonnet ~$0.01/req。Proヘビーユーザー（月30回Sonnet）で約$0.30/月。~~ in-app AI 機能廃止により本論点は解消。変動費/BEP は AI 原価抜きで再計算が必要（未実施）。

### 価格弾力性の推定（MAU 10,000人時）

| 価格 | 推定転換率 | 有料ユーザー | MRR           | サポート負荷 |
| ---- | ---------- | ------------ | ------------- | ------------ |
| $3   | 8-12%      | 800-1,200    | $2,400-$3,600 | 高           |
| $5   | 5-8%       | 500-800      | $2,500-$4,000 | 中           |
| $8   | 3-5%       | 300-500      | $2,400-$4,000 | 低           |
| $10  | 2-4%       | 200-400      | $2,000-$4,000 | 最低         |

**どの価格帯でもMRR中央値は約$3,000**（単位弾力的）。差が出るのはサポートコスト、AI原価、チャーン率、ユーザー品質。

### 各価格帯の評価

#### $3/月 — 不推奨

- 981人の有料ユーザーが必要。ニッチカテゴリで非現実的
- インフラ原価吸収のマージンが薄い（旧: AI原価吸収。in-app AI 廃止により論点変化、結論への影響は軽微）
- 「安い = すぐ解約」の心理でチャーン率が高い
- 年額割引の余地もない（$36/年 → $30にしても月$2.5）

#### $5/月 — 現行、ローンチ適正価格

- 577人で目標到達。困難だが可能
- 「衝動購買の閾値」以下
- 現在の Pro 特典で正当化できるギリギリの水準
- リスク: $5で始めると$5に永遠に縛られる可能性

#### $8/月 — 最も健全なビジネスモデル（機能追加後）

- 359人で目標到達。$5より38%少ないユーザー数で同じ収入
- 粗利率が高く、インフラスケールを吸収可能
- ただし、$8を正当化するには追加が必要:
  - Googleカレンダー双方向同期
  - ルールベース統計の深化（月次トレンド、補正提案）
  - Webhook / 外部連携（MCP/API 経由の外部 AI 接続の充実含む）
- 年額 $60/年（$5/月相当）で $5 層もカバーできる

#### $10/月 — 時期尚早

- 286人で到達可能だが、$10の心理的壁を越える「プレミアム感」が必要
- マルチデバイス、高度な予測分析、MCP/API の深い連携が前提
- Gcal同期 + プラットフォーム化が実現した段階で検討

### Van Westendorp 価格感度（4ペルソナ）

|                       | 安すぎて不安 | お得     | 高いが許容 | 高すぎ  |
| --------------------- | ------------ | -------- | ---------- | ------- |
| フリーランス(28歳,JP) | $2           | $3-4     | $7-8       | $12     |
| エンジニア(32歳,US)   | $2           | $5       | $10-12     | $20     |
| 大学生(20歳,DE)       | -            | $1-2     | $3-4       | $7      |
| **PM(35歳,US)** 🆕    | **$3**       | **$5-8** | **$15**    | **$25** |

**最適価格ポイント: $5**（3/4ペルソナが許容）
**アップサイド価格: $8**（PM層は「適正」、フリーランスは「圧を感じる」）

### PM ペルソナの発見（Round 2 で追加）

既に Sunsama $16 + Notion $8 に課金中のプロダクトマネージャー:

- $5だと「大丈夫？サステナブルなの？」と**逆に不安**
- **$8が「適正」**。$10でも払う
- MCP/API連携だけで$8の価値がある
- 年払い即決。会社のPD予算で落とせる可能性も
- **この層がDayoptの最優先ターゲット**

### Devil's Advocate: Round 2 の核心指摘

> **「有料ユーザーが0人の段階で$5が正しいか$8が正しいかの議論は意味がない。Stripeを繋いで、実際に課金して、解約理由を聞け」**

> **「$5で始めると$5に永遠に縛られる。$8で始めて$5に下げるのは歓迎される。逆は反発される」**

> **「開発者自身に問う: もし今日Dayoptが他人のプロダクトだったら、$5払うか？」**

### 推奨価格ロードマップ

| Phase                        | 価格                | 条件                        |
| ---------------------------- | ------------------- | --------------------------- |
| **ローンチ**                 | $5/月               | 現在の機能セットで PMF 検証 |
| **Gcal同期 + MCP/API強化後** | $8/月（新規から）   | 既存$5ユーザーは据え置き    |
| **年額**                     | $60/年（$5/月相当） | $8月額と併売。$5層をカバー  |

### Free tier 強化案: データ保持90日制限

> 「ユーザーが3ヶ月使い続けて"過去のデータが消える"となったとき、$5-8の支払いは合理的な選択になる」

| 機能         | Free            | Pro            |
| ------------ | --------------- | -------------- |
| データ保持   | **90日**        | 無制限         |
| タグ         | 3個             | 無制限         |
| 指標         | 4/8（基本のみ） | 全8 + チャート |
| エクスポート | なし            | CSV/JSON       |
| API/MCP      | なし            | あり           |

> Strategist提案。データ保持制限は最も強力なアップグレード動機になりうる。
