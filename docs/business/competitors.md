## 競合プロファイル

各社の規模感と脅威度。Dayoptとの距離が近い順に並べている。

### Sunsama — 最も思想が近い競合

| 項目       | 詳細                                                                   |
| ---------- | ---------------------------------------------------------------------- |
| 設立       | 2013年                                                                 |
| 資金調達   | ~$2.75M（少額）                                                        |
| チーム規模 | 7–10人                                                                 |
| 売上       | ~$1.5M/年（2024）                                                      |
| 特徴       | 少人数・ブートストラップ寄り。バーンアウト防止の思想がDayoptに最も近い |

**脅威評価**: Sunsama がemotional safety方向に舵を切ると、「判定しないプランナー」ポジションで直接競合になりうる。ただし$20/月の価格帯と無料枠なしがDayoptとの参入障壁。

**Dayoptへの乗り換えストーリー**: 「Sunsamaの哲学は好きだったけど、$20/月は高い。タスク管理機能は別のツールで足りてるので、時間配分だけに集中したい」

### Structured — 価格帯とミニマリズムが最も近い

| 項目         | 詳細                                                        |
| ------------ | ----------------------------------------------------------- |
| 設立         | ~2021年                                                     |
| 資金調達     | ブートストラップ（VCなし）                                  |
| チーム規模   | 12人                                                        |
| ダウンロード | 700万（iOS） / 30万/月                                      |
| 売上         | ~$200K/月                                                   |
| 特徴         | Apple中心のモバイルファースト。タイムラインUIがDayoptに類似 |

**脅威評価**: パターン認識やPlan/Recordの2レーン比較を追加した場合、価格帯×ミニマリズム×タイムラインUIの3軸で最も近い競合になる。ただし現状はタスクプランナーの域を出ない。

**Dayoptへの乗り換えストーリー**: 「Structuredのシンプルさは好きだけど、記録（Record）の概念がない。計画と実績のギャップを振り返りたい」

### Motion — 最大の資金力を持つプレイヤー

| 項目       | 詳細                                                 |
| ---------- | ---------------------------------------------------- |
| 設立       | 2019年                                               |
| 資金調達   | $102M+（Series C2、評価額$550M）                     |
| チーム規模 | 65–119人                                             |
| 有料顧客   | 10,000+（2025年）                                    |
| 売上       | ~$10M/年、YoY 300%成長                               |
| 特徴       | AI-first。圧倒的な資金力で全方位のプロダクトを構築中 |

**脅威評価**: B2C特化プランを出した場合、AI自動化 vs 手動配分の価値観対決になる。ただしMotionの思想（「AIに任せろ」）はDayoptの思想（「自分で決めろ」）と正反対のため、ターゲット顧客が根本的に異なる。

**Dayoptへの乗り換えストーリー**: 「Motionが全部決めてくれるのは楽だけど、自分の意思決定が消えた気がする。時間の使い方を自分で考えたい」

### Reclaim.ai — Dropbox傘下のAIスケジューラー

| 項目       | 詳細                                             |
| ---------- | ------------------------------------------------ |
| 設立       | 2019年                                           |
| 資金調達   | ~$9.5M → 2024年8月 Dropboxが買収                 |

**Dayoptへの乗り換えストーリー**: 「Reclaimはチームのカレンダー最適化には良いけど、個人の時間パターンを深く理解するツールとしては物足りない」

### Akiflow — キーボードファーストのニッチプレイヤー

**Dayoptへの乗り換えストーリー**: 「タスクの統合は便利だけど、結局"何をやるか"の管理ばかりで、"時間をどう使ったか"は見えない」

**脅威評価**: 低い。統合カレンダーとしてのポジショニングがDayoptと異なる。プライバシー重視は共感点だが、コア体験が違う。

**Dayoptへの乗り換えストーリー**: 「複数カレンダーの統合は便利だけど、"見る"だけで"意図を設計する"ことはできない」

### 価格ポジション分析

- **低価格帯**: Dayopt ($5/月) と Structured ($6.99/月、$29.99/年) が低い

- **Dayoptの優位**: Free枠で「タイムボクシングの基本体験」を完全提供しつつ、有料は$5でSunsama的な機能セットを実現
- **コンバージョン設計**: 「もっと自分の時間の使い方を理解したい」が課金トリガー。効率化への欲求ではなく、自己認識への欲求で課金させる設計は競合と異質

### 哲学マップ（2軸ポジショニング）

```
          効率重視（Do More）
               ↑
               |
  Motion ◉     |     ◉ Reclaim
               |
  Akiflow ◉    |     ◉ Morgen
               |
自動化 ←———————+———————→ 手動制御
               |
      Amie ◉   |   ◉ Sunsama
               |
               |  ◉ Structured
               |
               |        ★ Dayopt
               ↓
          認識重視（See Clearly）
```

**読み方**:

- 横軸: ユーザーの時間配分をAIが決めるか、ユーザー自身が決めるか
- 縦軸: ゴールが「より多くこなす」か「自分の時間の使い方を理解する」か
- Dayoptは**右下の独占ポジション** — 手動制御 × 認識重視の象限に唯一位置する

## ERRCグリッド（Blue Ocean 4アクション）

Strategy Canvasの4アクションを競合との対比で整理。

### Eliminate（排除）

Dayoptが**意図的にゼロにした**もの。これにより競合とvalue curveが交差しない。

| 排除した機能                             | 競合での位置づけ                  | 排除の理由                                                                                                                                     |
| ---------------------------------------- | --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Task management（完了/優先度/期限）      | Akiflow・Motion・Structuredの中核 | Dayoptは「いつ・どれだけ」のレイヤー。「何を」は別ツールの領域                                                                                 |
| Calendar attributes（参加者/場所/招待）  | Reclaim・Morgen・Amieの中核       | 外部コミットメントの管理はカレンダーの仕事                                                                                                     |
| AI auto-scheduling                       | Motion・Reclaimの差別化軸         | 自ら配分を決める行為がタイムボクシングの本質                                                                                                   |
| Recurrence rules（全自動生成・自動確定） | 全競合が提供                      | 提案型ルーティン（ゴースト+ワンタップ確定）で入力効率と選択型ログの主体性を両立。全自動確定は非採用のまま（[strategy.md §4-3](./strategy.md)） |
| Productivity score / streaks             | Motion（部分的）                  | スコアは判定を生む。Dayoptは判定しない                                                                                                         |
| Team collaboration                       | Motion・Reclaim・Amie             | 個人の鏡。他者に見せないからこそ本音の配分ができる                                                                                             |
| Meeting intelligence（録音/要約）        | Akiflow・Amie                     | 会議管理ではなく、会議に「配分した時間のパターン」を見る                                                                                       |
| Granular notifications（5/15/30分前）    | 全競合が提供                      | カレンダーパラダイム。ブロック境界の遷移シグナルのみ                                                                                           |

### Reduce（削減）

| 削減した要素         | 競合比                                                             | 理由                                                  |
| -------------------- | ------------------------------------------------------------------ | ----------------------------------------------------- |
| ブロック情報密度     | タグ+一言メモ（タイトル欄なし）。競合はタイトル+説明+ラベル+優先度 | 配分レイヤーの情報のみ。実行レイヤーは別              |
| 能動的な分析操作     | ユーザー操作なし。競合はレポート生成・カスタムビュー               | ルールベース統計がパッシブに発見（in-app AIではない） |
| 通知の複雑さ         | ON/OFF のみ。競合は5/15/30分前 + カスタム                          | ブロック遷移の瞬間だけが重要                          |
| 設定・カスタマイズ面 | 最小限。競合は豊富なテーマ・レイアウト設定                         | 認知負荷の削減                                        |

### Raise（強化）

| 強化した要素                 | Dayopt                                                                     | 最も近い競合                                                 |
| ---------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Intent vs Reality comparison | Plan + Record の2レーンタイムライン                                        | なし（Sunsamaに日次振り返りがあるが2レーンUIではない）       |
| Passive pattern insights     | ルールベース統計が自動でパターン発見（MCP/API 経由で外部 AI が深掘り可能） | Motion/Reclaimの自動化は「指示の代行」であり「発見」ではない |
| Emotional safety             | ゼロ判定デザイン                                                           | Sunsamaが部分的（バーンアウト防止の文脈で）                  |
| Full-day time overview       | 日の全体像がプライマリUI                                                   | Structuredが近いが、タスクリスト色が強い                     |

### Create（創造）

Dayoptが市場に**初めて持ち込んだ**もの。

| 創造した価値                   | 説明                                                   | 競合での該当 |
| ------------------------------ | ------------------------------------------------------ | ------------ |
| Schedule Allocation カテゴリ   | 時間配分に特化したプロダクトカテゴリ自体が新規         | なし         |
| Allocation pattern discovery   | 週・月単位の配分パターンを自動発見                     | なし         |
| Chronotype-aware visualization | ユーザーのクロノタイプに応じた時間帯の最適化表示       | なし         |
| Palette                        | 頻出ブロックの自動浮上。Recurrenceなしで入力効率を解決 | なし         |
| Intent evolution tracking      | 計画がどう変化したかの追跡                             | なし         |
| Positive unallocated time      | 未配分時間を「余白という選択」として肯定的に表現       | なし         |

## 勝ち負け明確化

### Dayoptだけが勝てる5つのポイント

Value curveが競合と交差しない、Dayopt固有の強み。これらを1社でも持っている競合は**存在しない**。

1. **Schedule Allocation カテゴリの創造** — 時間配分に特化したツールは他に存在しない。カレンダーでもタスク管理でも時間記録でもない第4のカテゴリ
2. **Plan / Record の2レーン比較** — 意図と現実のギャップを可視化する。Sunsamaの日次振り返りは最も近いが、同じ時間軸の2レーンUIではない
3. **Emotional safety** — スコア・ストリーク・赤マーク一切なし。判定しないデザイン。Sunsamaが「穏やかさ」を謳うが、タスク完了率は追跡する
4. **$5/月 + 充実Free枠** — Sunsama的な思想をFantastical的な価格で。衝動購買閾値以下。Free枠ありは8社中3社のみ
5. **Palette** — リカーレンスルールなしで入力効率を解決。毎日の意図的配分を保存。7社全てがRecurrenceを提供するなか、唯一の代替アプローチ

### 意図的に戦わない5つのポイント

Eliminateは「できない」ではなく「やらない」。Blue Oceanの非交差value curveを維持するための戦略的判断。

| 競合の強み             | Dayoptが戦わない理由                                       | もし追加したら何が壊れるか                           |
| ---------------------- | ---------------------------------------------------------- | ---------------------------------------------------- |
| AI自動スケジューリング | ユーザーが自ら配分を決める行為こそがタイムボクシングの本質 | 「自分のキャンバス」感が消え、Motionの劣化版になる   |
| タスク管理             | 「いつ・どれだけ」のレイヤーに集中。「何を」は別ツール     | ブロック情報密度が上がり、タグ中心入力の簡潔さが崩壊 |
| チーム機能             | 個人の鏡。他者に見せないからこそ本音の配分ができる         | 「見られている」意識がデータの正直さを損なう         |
| Meeting intelligence   | 会議管理ではなく、会議に「配分した時間のパターン」を見る   | プロダクトの焦点がカレンダー機能に引きずられる       |
| 30+のIntegration       | 閉じたシステムがパターン認識の精度を保つ                   | 外部データのノイズがシグナルを希釈する               |

### 今後の検討余地

| 項目                   | 現状            | 検討理由                                     | Blue Ocean整合性                                       |
| ---------------------- | --------------- | -------------------------------------------- | ------------------------------------------------------ |

## 戦略的示唆

### なぜDayoptは競合と戦わなくていいのか

1. **非交差のvalue curve** — 競合が高スコアの領域でDayoptはゼロ。DayoptがHighの領域で競合はゼロ。直接競合が発生しない
2. **異なる購買動機** — 競合ユーザーは「もっとこなしたい」。Dayoptユーザーは「自分の時間の使い方を理解したい」
3. **異なる非顧客層にリーチ** — 生産性ツールに抵抗感のあるクリエイター・フリーランス・内省的な人々はDayoptの非判定的デザインにこそ惹かれる
4. **価格帯の非競合** — $5/月は競合の1/4〜1/6。「試してみよう」のハードルが根本的に異なる
5. **置換の構造** — TogglはRecordで不要に。Google CalendarはPlanで不要に。タスク管理だけが共存する。競合は「どれかを置換する」が、Dayoptは「複数を同時に置換する」

### 監視すべき動向

| 競合           | 監視ポイント                            | 脅威度 | トリガー                                          |
| -------------- | --------------------------------------- | ------ | ------------------------------------------------- |
| **Sunsama**    | emotional safety 方向への舵切り         | 高     | 「判定しないプランナー」ポジション宣言            |
| **Structured** | Pattern discovery / Record layer の追加 | 高     | 価格帯 × ミニマリズム × タイムラインUIが3軸で競合 |
| **Motion**     | B2C特化の低価格プラン                   | 中     | AI自動化 vs 手動配分の価値観対決                  |
| **Reclaim**    | Dropbox統合でB2C回帰                    | 低     | エンタープライズ方向に進む可能性のほうが高い      |
| **新興**       | Plan + Record overlay を持つ新規参入者  | 中     | Dayoptの核心機能をコピーされるリスク              |

### 競合にコピーされにくい理由

1. **思想の深さ** — 機能コピーは容易だが、「判定しない」デザイン思想を全プロダクトに一貫させるのは別の能力
2. **既存ユーザーの期待** — Motionユーザーは自動化を、AkiflowユーザーはIntegrationを求める。既存プロダクトからDayopt的機能を追加すると既存顧客の期待と矛盾する
3. **Paletteの体験設計** — Recurrenceを捨ててPaletteに置き換える判断は、既存ユーザーがいるプロダクトでは実行困難

## 周辺競合（時間記録・タスク管理カテゴリ）

上記は Schedule Allocation カテゴリで直接競合しうる7社。以下は隣接カテゴリ（時間トラッキング・タスク管理・習慣化）の競合で、Dayoptとは軌道が異なるため脅威度は低いが、UI/UX・マーケティング・価格戦略の参考として定期的に観測する。

### 直接競合（時間記録・タイムトラッキング）

| サービス     | 特徴                   | ターゲット           | 価格帯       |
| ------------ | ---------------------- | -------------------- | ------------ |
| Toggl Track  | シンプルな時間記録     | フリーランス・チーム | 無料〜$18/月 |
| Clockify     | 無料の時間トラッキング | 個人・チーム         | 無料〜$12/月 |
| RescueTime   | 自動トラッキング       | 生産性向上したい人   | 無料〜$12/月 |
| Timing (Mac) | 自動記録・Mac専用      | Mac開発者            | $8〜$14/月   |

| サービス | 特徴                         | ターゲット      |
| -------- | ---------------------------- | --------------- |
