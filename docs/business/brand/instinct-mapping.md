# 本能マッピングとターゲット定義

## サマリー（第三者向け説明）

### このドキュメントは何か

「Dayoptを使う人はどんな人で、何を求めているのか」を、進化心理学に基づく動機理論で整理したもの。

### 結論

Dayoptは「内向きの充実」を求める人のためのツール。

**刺激する本能（6つ）:**

- 高める・進める（メイン）→ 「整った」「前に進んだ」
- 決する・物語る（サブ）→ 「自分で選んだ」「意味がある」
- 安らぐ・有する（補助）→ 「安心」「蓄積」

**刺激しない本能（2つ）:**

- 属する・伝える → コミュニティなし、シェアなし

**向く人:** SNS疲れ、承認欲求からの解放を求める人
**向かない人:** みんなでやりたい、見せたい、ご褒美が欲しい人

### なぜこの整理が必要か

1. **機能開発の判断基準** → この本能に刺さるか？
2. **マーケティングメッセージ** → どの本能に訴えかけるか
3. **向かない人の明確化** → 無駄な獲得コストを避ける
4. **競合との差別化** → 「内向きの充実」特化

## 理論的背景と出典

本ドキュメントは、進化心理学に基づく動機理論をマーケティングに応用したフレームワークを使用している。

### 学術原典

**Forbes, David L. (2011). "Toward a Unified Model of Human Motivation"**
Review of General Psychology, Vol. 15, No. 2, 85-98.
DOI: 10.1037/a0023483

Forbesは過去1世紀の動機理論を「化学の周期表」のように体系的に統合。106の動機概念を3×3マトリックス（9領域）に整理した。

### マーケティング応用

**鈴木祐『進化論マーケティング』**

Forbesの9領域を、日本語の動詞で覚えやすい「8つの本能」に再構成。実践的なマーケティングフレームワークとして提示。

### 理論的限界と最新研究

**Forbes (2011)の限界（学術的に指摘されている問題）:**

- 生物学的動機と認知的動機の区別がない
- 理論的焦点が狭い（一部の動機理論のみカバー）
- 動機を独立した力として扱い、相互連関を無視
- **精神的領域（正義・道徳・超越）が欠如**

**Pincus (2022-2024)による更新:**

- Forbes 9セル → 12セルに拡張
- 4つ目の領域「Spiritual（精神的）」を追加
- Justice（正義）、Moral（道徳）、Transcendental（超越）をカバー
- 2023年: "The structure of human motivation" (BMC Psychology)
- 2024年: "Well-being as Need Fulfillment" (Integrative Psychological and Behavioral Science)

**Dayoptへの影響:**
精神的領域（正義・道徳・超越）はDayoptの文脈に関係しないため、Forbes (2011) + 鈴木祐の8本能フレームワークで十分と判断。

## Forbes 3×3マトリックスと8つの本能

### Forbesの構造

**行：Where?（変化はどこで起こるか）**

| 英語          | 日本語 | 意味       |
| ------------- | ------ | ---------- |
| Intrapsychic  | 内心的 | 自己の内部 |
| Instrumental  | 道具的 | 物質世界   |
| Interpersonal | 対人的 | 社会世界   |

**列：What type?（どんな種類の変化か）**

| 英語   | 日本語 | 時間軸               |
| ------ | ------ | -------------------- |
| Being  | 存在   | 未来志向（期待）     |
| Doing  | 行動   | 今この瞬間（体験）   |
| Having | 所有   | 過去振り返り（結果） |

### Forbes 9セルの正式名称

|                             | Being（存在） | Doing（行動） | Having（所有） |
| --------------------------- | ------------- | ------------- | -------------- |
| **Intrapsychic（内心的）**  | Security      | Identity      | Mastery        |
| **Instrumental（道具的）**  | Empowerment   | Engagement    | Achievement    |
| **Interpersonal（対人的）** | Belonging     | Nurturance    | Esteem         |

### 各セルの定義

**内心的（自己内）**

| セル   | 英語名       | 定義                                       |
| ------ | ------------ | ------------------------------------------ |
| Being  | **Security** | 安全で自信を持ち、心配から解放される       |
| Doing  | **Identity** | 個人の好み・スタイル・価値観を反映した行動 |
| Having | **Mastery**  | 個人の才能と強みの完全な実現               |

**道具的（物質世界）**

| セル   | 英語名          | 定義                                         |
| ------ | --------------- | -------------------------------------------- |
| Being  | **Empowerment** | タスクに対等で、能力があり、自由に行動できる |
| Doing  | **Engagement**  | 活動への没頭・従事                           |
| Having | **Achievement** | 達成・成果の獲得                             |

**対人的（社会世界）**

| セル   | 英語名         | 定義                                           |
| ------ | -------------- | ---------------------------------------------- |
| Being  | **Belonging**  | 他者との関係性に繋がっている                   |
| Doing  | **Nurturance** | 愛する・ケアする・協力することで良い気分になる |
| Having | **Esteem**     | 社会的ネットワークでの地位と尊敬を得る         |

### Forbes 9セル → 鈴木祐 8つの本能

| Forbes        | 英語名      | 鈴木祐                  | 定義                                       |
| ------------- | ----------- | ----------------------- | ------------------------------------------ |
| 内心的×Being  | Security    | **安らぐ**              | 心身の危険から離れて不安や恐怖から逃れたい |
| 内心的×Doing  | Identity    | **物語る**              | 自分の人生に大きな意味を感じたい           |
| 内心的×Having | Mastery     | **進める**              | 明確なゴールを設定し、それをクリアしたい   |
| 道具的×Being  | Empowerment | **決する**              | 自分の行動や目標を自分で決めて実行したい   |
| 道具的×Doing  | Engagement  | （統合）                | 活動への没頭                               |
| 道具的×Having | Achievement | **有する**              | 生存に役立つ物や情報を蓄積したい           |
| 対人的×Being  | Belonging   | **属する**              | 特定のグループやコミュニティに入りたい     |
| 対人的×Doing  | Nurturance  | （統合）                | ケア・協力                                 |
| 対人的×Having | Esteem      | **高める** / **伝える** | 地位につきたい / アピールしたい            |

※ 9→8への変換で、Engagement・Nurturanceは他の本能に統合。Esteemは「高める」「伝える」に分割。

## Dayoptが刺激する本能

### 採用した本能（6つ）

Dayoptは「内心的領域」に特化したツール。以下の6本能を刺激する。

| 優先度     | 本能   | Dayoptでの体験                     | 対応機能                       |
| ---------- | ------ | ---------------------------------- | ------------------------------ |
| **メイン** | 高める | 「今日も整った」という自己効力感   | Record完了、カレンダー表示     |
| **メイン** | 進める | 「少しでも前に進んだ」実感         | 進捗の可視化、ストリーク       |
| サブ       | 決する | 「自分で選んだ時間」という自律感   | Plan機能、選択型ログ           |
| サブ       | 物語る | 「自分はこう生きている」という意味 | 振り返り、パターン発見         |
| 補助       | 安らぐ | 「整理できた」という安心感         | シンプルなUI、プレッシャーなし |
| 補助       | 有する | ログという「資産」が蓄積される     | 記録の蓄積、データ保持         |

### 採用しなかった本能（2つ）

| 本能       | 不採用の理由                                                                  |
| ---------- | ----------------------------------------------------------------------------- |
| **属する** | Dayoptは個人向けツール。コミュニティ機能なし。「一人で整える」に特化          |
| **伝える** | SNS連携・シェア機能なし。「自分のための記録」であり、他者へのアピールではない |

※ 将来的にコミュニティ機能やシェア機能を追加する場合は再検討

### スコープ外：「没頭（Engagement）」

**判断：Dayoptは「没頭」をサポートしない**

| 理由                     | 詳細                                               |
| ------------------------ | -------------------------------------------------- |
| 常に見ていない           | Dayoptは「記録時」に開くツール。活動中は見ない     |
| ゲーミフィケーションなし | 没頭を促すにはリアルタイムのフィードバックが必要   |
| 記録ツールの本質         | 「後から振り返る」ものであり「今この瞬間」ではない |

**Dayoptは「Before（計画）」と「After（記録）」のツール。「Now（没頭）」は扱わない。**

| 機能       | 時間軸         | Forbes概念            |
| ---------- | -------------- | --------------------- |
| **Plan**   | Before（未来） | Empowerment, Identity |
| **実行中** | Now（今）      | **何もない**          |
| **Record** | After（過去）  | Mastery, Security     |

**競合との棲み分け:**

| ツール     | フォーカス               | Forbes概念             |
| ---------- | ------------------------ | ---------------------- |
| Forest     | 没頭中（スマホを見ない） | Engagement             |
| Focusmate  | 没頭中（誰かと一緒に）   | Engagement + Belonging |
| Toggl      | 没頭中（タイマー）       | Engagement             |
| **Dayopt** | 没頭後（振り返り）       | Mastery + Security     |

没頭は他ツールに任せる。Dayoptは「没頭できた結果」を記録する。

## Dayoptを好む人の本能プロファイル

### 本能バランスチャート

```
高める ████████████ 強い（自己評価重視）
進める ██████████   強い（前進実感重視）
決する ████████████ 強い（自律性重視）
物語る ████████     やや強い（意味を求める）
安らぐ ██████       普通（不安は適度にある）
有する ████         弱い（物質より時間の質）
属する ██           弱い/疲れ（一人で良い）
伝える ██           弱い/疲れ（見せたくない）
```

### 本能別の特徴

**「強い」本能**

| 本能       | 特徴                         | なぜDayoptを好むか                                         |
| ---------- | ---------------------------- | ---------------------------------------------------------- |
| **高める** | 自分の中での評価を大事にする | 他人の評価より「自分で整った」と感じたい                   |
| **進める** | 小さくても前に進みたい       | 大きな成果より「今日も動けた」が欲しい                     |
| **決する** | 自分で選びたい               | 誰かに決められた予定ではなく「自分で選んだ時間」でありたい |
| **物語る** | 人生に意味を求める           | 行動がバラバラでなく「自分の物語」として繋がってほしい     |

**「弱い」または「疲れている」本能**

| 本能       | 特徴                              | なぜDayoptを好むか                               |
| ---------- | --------------------------------- | ------------------------------------------------ |
| **属する** | コミュニティ帰属欲求が低い/疲れた | SNSの「みんなと繋がる」に疲れた。一人で整えたい  |
| **伝える** | 自己アピール欲求が低い/疲れた     | 誰かに見せるためじゃなく、自分のために記録したい |
| **有する** | 物質的蓄積への執着が薄い          | モノより「時間の質」を大事にする                 |

### 核心的な洞察

> **Dayoptを好む人は「内向きの充実」を求めている**

- 外からの承認（伝える）ではなく、自分の中の納得（高める）
- みんなと一緒（属する）ではなく、自分だけの整理（決する）
- 物質的な蓄積（有する）ではなく、時間の質（進める・物語る）

**これは「SNS疲れ」「承認欲求からの解放」を求める層と重なる。**

## Dayoptが向かない人

### 本能プロファイル：不適合パターン

```
属する ████████████ 強い → コミュニティで一緒にやりたい
伝える ████████████ 強い → SNSでシェアして「いいね」が欲しい
有する ████████████ 強い → ポイントやバッジを集めたい
```

### 詳細

| 本能が強い人       | 理由                                                            | 代替として向いているツール   |
| ------------------ | --------------------------------------------------------------- | ---------------------------- |
| **属する**         | コミュニティ機能がない。仲間と一緒にやりたい人には物足りない    | Habitica、みんチャレ等       |
| **伝える**         | シェア機能がない。SNSに投稿して「いいね」が欲しい人には向かない | 公開日記系アプリ             |
| **有する（物質）** | 物理的な報酬がない。ポイントやバッジを集めたい人には弱い        | ゲーミフィケーション系アプリ |

### 向かない人の特徴まとめ

- **「みんなでやりたい」人** → 一人で黙々と整えるDayoptは孤独に感じる
- **「見せたい」人** → シェア機能がないのでモチベーションが続かない
- **「ご褒美が欲しい」人** → 外発的報酬がないので物足りない
- **「完璧主義」の人** → ゆるさがストレスになる可能性

## Dayoptの位置づけ（Forbes領域で整理）

### カバー範囲

```
              Being        Doing         Having
            （存在）      （行動）       （所有）

内心的      Security  →  Identity   →  Mastery
             安らぐ       物語る        進める
              ✓            ✓            ✓

道具的      Empowerment → Engagement → Achievement
             決する        没頭         有する
              ✓            ✗            ✓

対人的      Belonging  →  Nurturance →  Esteem
             属する        ケア         高める
              ✗            ✗            △（内向き）
```

※ 対人的領域の「高める」は、Dayoptでは「他者からの評価」ではなく「自己評価」として再解釈

### 体験の流れ

```
Forbes 3領域のうち、Dayoptは「内心的領域」に特化

         期待        体験        結果
        (未来)      (今)       (過去)
内心的   物語る  →   進める   →  高める
         ↑________________________↑
              「決する」が横断
              （自分で選ぶ感覚）
```

**Dayoptが提供する体験の流れ：**

1. **Plan（期待）**: 「こう過ごしたい」を選ぶ → 物語る・決する
2. **実行（体験）**: 選んだ時間を過ごす → （Dayopt外）
3. **Record（結果）**: 「整った」と感じる → 高める・進める

## ターゲット定義と分類

### 分類定義

| 種類               | 定義                                             | 役割                                                 |
| ------------------ | ------------------------------------------------ | ---------------------------------------------------- |
| **戦略ターゲット** | 将来的に広く届けたい理想の利用者層               | 認知拡大・スケーラビリティを前提とした"広い見立て"   |
| **コアターゲット** | 現段階で最も刺さりやすく、利用が期待できる人たち | 最初の共感・継続・課金の中心を担う"具体的なペルソナ" |

### 戦略ターゲット向け：価値マップ

| 領域       | 内容                                                                 |
| ---------- | -------------------------------------------------------------------- |

| 認知的価値 | 自分の行動や選択が"意味あるもの"として整理される                     |
| 情緒的価値 | 「今日は、自分で決めて動けた」という満足感と自信                     |

| 社会的価値 | 他人に合わせず「私は私でいい」と思える感覚が生まれる                 |
| 回避価値   | タスクに追われて「何のためにやってるか分からない」状態から抜け出せる |

## 戦略ターゲット

### 戦略ターゲット（広義）

> **「人生の選択や時間配分を"自分の軸"で決めたい人すべて」**

| 属性     | 内容                                                       |
| -------- | ---------------------------------------------------------- |
| 年齢層   | 20代中盤〜40代前半                                         |
| 状況     | 忙しく、かつ自分を見失いたくないと感じている人             |
| 意識     | 自分の行動に"意味"や"整合性"を求めている／効率より納得感   |
| 職業     | 自営業、フリーランス、マネージャー、リモートワーカーなど   |
| 行動特性 | タスク管理・ジャーナル経験があるが、続かなかった経験を持つ |

### ターゲットの心理的特徴

- 「やるべきこと」は毎日こなしているが、**「これって、自分が選んだ日々なのかな？」**というモヤモヤを抱えている
- SNSや外の情報に流されず、**自分の"軸"で進みたい**とどこかで思っている
- 頑張りたいというより、**"整っていたい"**
- でも意識高い系のツールや習慣は**どこかしんどい**

### 行動面での共通性

- スケジュールやタスクは管理している（Googleカレンダー／Notionなど）
- 日記やログをつけた経験があるが、**続かない／続ける理由が見つからない**
- 他人に見せない「自分の整理のための記録」をどこかで求めている

### Dayoptが提供できる価値

- "ちゃんとできてる"という**実感と安心感**
- 「今日は自分で選んで動けた」という**自由の満足**
- 行動と価値観が繋がっていくことで生まれる**自己への信頼感**

### ターゲットの本能トリガー

1. **高める（自尊の改善）**
   → 自分はちゃんとできていると感じたい

2. **進める（習得の前進）**
   → 自分の癖や成長の兆しを掴みたい

3. **決する（自由の欲求）**
   → 自分の時間や行動を、自分で選びたい

### 一文でまとめるなら

> **「日々の忙しさに流されず、"自分で選んだ人生"を歩みたいと感じている人たち」**

## コアターゲット

### 統合ペルソナ：「整えたいけど、がんばれない人」

2つのタイプを統合した単一ペルソナ。

**過去の経験（タスク疲れ）:**

- タスク管理ツールや時間管理法をいろいろ試してきた
- 続かない、しんどい、完璧すぎて自分に合わないなどの挫折経験がある
- 本当は「行動を整えたい」気持ちはある
- ログや記録にも興味があるが、入力や運用が重いと続けられない

**現在の欲求（主体性回復）:**

- 日々の予定やタスクに流されがちで、「これは自分の時間だった」と思える瞬間が少ない
- 誰かに振り回されるのではなく、自分の軸で時間を使いたい
- 本当に大切なことに時間を使っているか、自分で確かめたい
- 小さくても「自分で選んだ時間だった」と感じられると、満たされる

**本能トリガー:**

- 高める・進める（UX寄り）: 「ゆるく整えるUX」で信頼を得る
- 決する・物語る（価値観寄り）: 「意味を思い出させる問い」で心に触れる

> **Dayoptは「整えたいけど、がんばりたくない人」のためのゆるく続けられるツール**

## 普通のユーザーの共感マップ

### パターン1: 会社員タイプ

**考えていること（Think）**

- 「このままでいいのかな？時間の使い方ズレてる気がする」
- 「毎日やることはやってるけど、自分のために動けてない気がする」
- 「ちゃんと整えてる人を見ると、ちょっと憧れる…けど、あれは無理」

**感じていること（Feel）**

- やることに追われていて、心の余裕がない
- タスク管理アプリや手帳は「ちゃんとできる人のもの」というプレッシャー
- 「整っていない自分」をなんとなく責めがち（でも重くはない）

**見ているもの（See）**

- SNSで「習慣化」「タスク管理」「ログライフ」の投稿を目にする
- YouTubeで「朝活」「整った1日ルーティン」系の動画を見てしまう
- 自分の周囲の人が、意外と"何もしてない"のも知っている（安心感）

**聞いていること（Hear）**

- 「続かないよね」「なんか疲れるよね」といった共感トーンの会話
- 一方で、「自己管理できる人は仕事もできる」的な社会の声も耳に入る
- 「自分なりでいいと思うよ」という励ましにも救われている

**主な課題（Pain）**

- 継続できないことで「また失敗か」と思いたくない
- やる気があるのに、習慣として定着しない
- 情報が多すぎて、自分に合うやり方がわからない

**期待する成果（Gain）**

- 完璧じゃなくても「整ってる感」が得られる
- 書かなくてもOK。でも「書きたくなる」感覚が自然に生まれる
- 「今日、自分で選んで動けた」感覚が得られるログと可視化

### パターン2: 在宅ワーカータイプ

**考えていること（Think）**

- 「ちゃんとやろうと思ってるのに、なんか気が乗らない」
- 「結局またスマホ見て終わっちゃったな…」
- 「無駄に過ごした気がするけど、何をどう変えたらいいか分からない」

**感じていること（Feel）**

- 少し自己嫌悪。だけど、落ち込みすぎるのもしんどい
- 何かを始めるエネルギーが出ない
- 一度止まると戻るのに時間がかかる

**見ているもの（See）**

- SNSで「日々を整える人」たちの投稿（どこか遠い世界に感じる）
- 読みかけの本やアプリが開きっぱなしになっている
- 家の中が少し散らかっていると気になるけど、手をつけられない

**聞いていること（Hear）**

- 「焦らなくていいよ」「自分のペースでね」という声（安心する反面、少し物足りなさも）
- 「もっと計画立てて動けばいいのに」と自分に言い聞かせるような思考
- ときどき、誰かの「続けてる」話に劣等感を感じる

**主な課題（Pain）**

- モチベーションが安定しない
- やる気が出るタイミングを逃すと、1日が無駄に感じる
- 自己管理ツールを立ち上げる気力すら湧かないときがある

**期待する成果（Gain）**

- やる気がない日でも、少しだけ動けた"証拠"が残ってほしい
- 自分のペースで戻ってこれる場所がほしい
- 記録が「プレッシャー」じゃなくて、「よりそい」になると続けられる気がする
