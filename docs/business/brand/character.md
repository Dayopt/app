# 🧭 Dayopt Brand Character 設計

## 1. 名前（仮）

**「コンパスさん」**
※正式名称は調整可能。ブランドコンセプト用。

💡 **メモ**: Dayopt → 略すと「DO」→「やる」という意味にもなる

### 🎯 ブランドコンセプト

> **わかってる人に、ちゃんとした道具を渡す。**

自分の時間を自分で経営したい人のためのツール。

---

## 2. 基本性格（Big Fiveパーソナリティ）

| 項目       | 特徴                                                   |
| ---------- | ------------------------------------------------------ |
| 誠実性     | 高：時間や記録を守ることに価値を置く                   |
| 開放性     | 中：柔軟だが押し付けない                               |
| 協調性     | 中：寄り添いすぎず、ユーザーの判断を信頼する           |
| 外向性     | 低〜中：必要なときだけ話しかける。余計なことは言わない |
| 神経症傾向 | 低：不安を煽らず、落ち着いた存在                       |

---

## 3. 話し方・態度（Tone of Voice）

- **静かに自信がある**：大げさに煽らない。「自分の時間を自分で決める人のための道具」という落ち着いたスタンス
- **知的だけど冷たくない**：データを扱うけど、目的は自己理解。「自分をよく知る」ための温かみ
- **余白がある**：詰め込まず、必要なことだけ言う。ユーザーが自分で考える余地を残す
- **対等な目線**：上から教えるのでも、下から寄り添うのでもない。「わかってる人」に道具を渡す姿勢

---

## 4. 見た目（Visual）

| 項目     | 内容                                            |

## 5. ジョブ理論的な役割と機能

### ✅ 担うべきジョブ（Jobs to be Done）：

- 自分の時間の使い方を自分でコントロールする
- 計画・実績・分析のサイクルを回す
- 意図と実態のギャップを可視化し、自己理解を深める

詳細なJTBD階層は [messaging.md](?path=/docs/strategy-brand-messaging--docs) を参照。

## 6. 差別化軸（他サービスとの違い）

| Dayopt                            | 他ツール（Notion, Todoistなど） |
| --------------------------------- | ------------------------------- |
| 意図と実態を1つの場所で重ねて見る | 計画と記録が別の場所            |
| 計画・実績・分析のサイクル        | 完了/未完了のチェックリスト     |
| 自分の時間を「経営」する道具      | タスクを「管理」するツール      |
| 内向きの充実・自己理解            | 生産性・合理性の最大化          |

## 7. インタラクション原則：「人の気配」を感じさせる

> **コーンって叩いたら、コーンって返ってくる感覚**
>
> — note CXO 深津さん

### 核心

インターネット最大のペインは「頑張ったのに虚空に消える」こと。
Dayoptは、ユーザーの行動に対して必ず「こだま」が返る体験を作る。

### 設計原則

| 原則             | 説明                                 | 具体例                     |
| ---------------- | ------------------------------------ | -------------------------- |
| **応答性**       | 重要なアクションには必ず反応がある   | ログ記録時のフィードバック |
| **人間の声**     | 機械的でなく「人が話している」感覚   | システムメッセージのトーン |
| **気配の可視化** | 背後に人間がいることを感じさせる     | 過去の自分の記録が見える   |
| **対話感**       | 一方通行でなく、やり取りしている感覚 | 振り返り時の問いかけ       |

### やること / やらないこと

| ✅ やること                        | ❌ やらないこと            |
| ---------------------------------- | -------------------------- |
| アクション後に温かいフィードバック | 無言で処理完了             |
| 過去の自分との「再会」を演出       | データを淡々と表示するだけ |
| 励ましや共感のある言葉             | 冷たいシステムメッセージ   |
| 適度なタイミングでの声かけ         | 過剰な通知・介入           |
