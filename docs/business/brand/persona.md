# ターゲットペルソナ

Dayoptの最初の顧客像。「誰に」を具体化する。

> ターゲットの要約は [`docs/product/concept.md`](../../product/concept.md) §3「AI を使いこなす知的労働者」を参照。本ドキュメントはその詳細な行動パターン・原体験を補足する。

---

## 1. ペルソナの核心

**「正しいやり方は分かってるのに、道具がない」人。** 中でも AI を使いこなす知的労働者（[concept.md §3](./concept.md)）を最初の楔とする。

- 時間管理に困ってる初心者ではない
- すでにいろいろ試して、自分なりの方法論を持ってる
- Toggl触ったことがある、タイムボクシングを知ってる、生産性について考えたことがある
- タスク管理や情報整理は既に AI や GitHub Issues / Notion 等に任せている
- 最初にお金を払うのは「もう何かしらやってる人」

---

## 2. ジムの比喩

プロダクトの価値は普遍的（運動が体にいいのと同じ）。ただし最初の顧客は「すでに走ってる人」。

ニッチを攻めるのは市場を狭くするためではなく、**最初の熱量を作るため**。

---

## 3. 行動パターン

### ツール遍歴

| ステップ | 行動                 | 結果                                                   |
| -------- | -------------------- | ------------------------------------------------------ |
| 1        | カレンダーで予定管理 | 「実績」が残らない                                     |
| 2        | Toggl等で時間記録    | 記録が面倒で続かない、または記録だけで改善に繋がらない |
| 3        | TODOアプリで管理     | 完了/未完了だけで「何時間使ったか」が見えない          |
| 4        | 複数ツール併用       | 行き来が面倒、データが分断、サイクルが回せない         |

### 心理的プロファイル

- **自分↔自分** の関係で完結する（他者への共有欲求が薄い）
- 「内向きの充実」を求める（参照: [instinct-mapping.md](?path=/docs/strategy-brand-instinct-mapping--docs)）
- SNS疲れ、承認欲求からの解放を求める傾向
- 「進める」「決する」「高める」の3本能が強い

---

## 4. 創業者の原体験 — Problemの起点

ペルソナの問題は、創業者自身の問題でもある。「痛み」ではなく「合理的な不満」が起点。

### 3つの不満

1. **既存ツールがそれぞれ中途半端** — Togglは記録だけで面倒。TODOは管理方法がバラバラ。カレンダーは予定だけ。
2. **本来一緒であるべきものが分かれてる** — 予定と記録は同じ「時間の使い方」なのに別のツールで管理。振り返りもブラッシュアップもしづらい。
3. **上位に確信がある** — タイムボクシングが最良の方法だと知っている。リソース配分を可視化したい。なのに最適化されたツールがない。

### LP向けリフレーミング

LPでは「道具の断片化」（下位ジョブ）ではなく、**「サイクルが回せない」（上位ジョブ）**から入る。

- 計画はカレンダーにある。記録はTogglにある。分析は…どこにもない。
- 3つのツールを行き来しても、このサイクルは回らない。
- だから明日を今日より良くする手がかりが得られない。

---

## 5. Before → After

|            | 状態                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------- |
| **Before** | 1日が終わって、何にどれだけ時間を使ったか説明できない。明日を今日より良くする手がかりがない。 |
| **After**  | 自分の時間の使い方が「見える」。だから明日を自分で設計できる。                                |
