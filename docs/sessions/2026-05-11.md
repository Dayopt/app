conventions:

- pure な集計ロジックは router ファイルに書かず独立モジュール (`tag-dashboard.ts` 等) に分離する。router は DB 呼び出し + エラーハンドリングのみ、変換は別ファイル
- tRPC procedure の Pro/Free 境界は proProcedure vs protectedProcedure で明示的に区別する。「認証済みなら全員使える機能」は protectedProcedure、「Pro のみ」は proProcedure

learned:

- Supabase `.or()` filter に user-controlled な datetime 文字列を直接補間するパターン（`and(start_time.lte.${endDate},...)`）は、Zod で `.datetime({ offset: true })` バリデーション済みなら PostgREST injection にならない（datetime 形式は `,` や `)` を含めない）
- useReviewDateDisplayProps から granularity を抜いた設計は Codex が回帰として検出した。hook が返す formatPattern / showWeekNumber が granularity に依存する場合は引数として受ける必要がある

tried_and_failed:

- useReviewDateDisplayProps の signature を `(currentDate: Date)` のみにリファクタ → Codex P2 で week/day/year の日付表示が崩れる回帰として指摘。翌日 granularity 引数を復元して修正
