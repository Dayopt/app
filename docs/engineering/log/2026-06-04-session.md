decisions:

- Supabase Preview Branching 運用へ移行。GitHub Actions の `supabase-migration.yml` を廃止し、Supabase CLI の preview branch 機能に一本化
- `.mcp.json` に playwright（stdio）と github（HTTP/OAuth）を追加。ブラウザ検証と PR 参照を MCP 経由で行う体制を整備
- `.claude/` 全体のパス・コマンド参照を旧単一アプリ構造（`src/`）からモノレポ構造（`apps/product/src/`、`packages/`、`apps/web/`）へ一括修正
- daily-end skill の別リポジトリ参照（`~/Desktop/web`）を削除。monorepo では `git log --all` が全 apps を含むため 1 コマンドで足りる

conventions:

- skill/rules 内のパス参照は `apps/product/src/` 起点で書く（`src/` 単独は不可）
- pnpm コマンドは `npm run` でなく `pnpm` で統一
- MCP 許可リストは `.claude/settings.json` の `alwaysAllow` に記載。追加時はセクションごとに整理する

breaking:

- `.github/workflows/supabase-migration.yml` 削除（Supabase Preview Branching に移行したため不要）
- `.claude/commands/daily-end.md` から ~/Desktop/web の別リポジトリ git log を削除

learned:

- 'Supabase Preview Branch は Auth SMTP をローカル supabase と同期しない。`supabase/config.toml` で `[auth.email]` の smtp 設定を preview 環境で無効化しないとメール送信エラーになる'
- '`git log --all` は monorepo 内の全ブランチ・全パスを含むため、apps/web や apps/product を別リポジトリ扱いする必要はない'
