learned:

- Opus 4.7 はネガティブ指示（Don't X）よりポジティブ例示（Do Y, like `...`）への遵守率が高い
- Opus 4.7 は 4.6 比で subagent / skill の自動起動が控えめ。発動条件の明示化（When to Use / When NOT to Use）が必要
- commitlint の subject-case は日本語サブジェクト先頭の英大文字略語を upper-case として拒否する。`MCP サーバー...` / `[ADR-007](../../operations/log/2026-02-16-cookie-consent-banner.md) ...` 始まりは通らず、`各 MCP ...` / `コーディング規範 ... ([ADR-007](../../operations/log/2026-02-16-cookie-consent-banner.md))` などに言い換えが必要
- Stop hook で `afplay /System/Library/Sounds/Glass.aiff` を `async: true` で鳴らすと、セッション終了をブロックせず完了通知が得られる
- Opus 4.7 auto mode（Shift+Tab 切替）は「事前コンテキスト十分 + 機械的展開」タスクで推奨。schema / RLS 変更や design decision を含むタスクでは使わない

tried_and_failed:

- コミット `docs(rules): MCP サーバー利用ガイドラインを追加` は commitlint (subject-case upper-case) で拒否。先頭を `各 MCP サーバー...` に変更して通した。同様に `docs(adr): [ADR-007](../../operations/log/2026-02-16-cookie-consent-banner.md) ...` も `docs(adr): コーディング規範ポジティブ例示化の記録 ([ADR-007](../../operations/log/2026-02-16-cookie-consent-banner.md)) ...` に言い換えが必要だった
