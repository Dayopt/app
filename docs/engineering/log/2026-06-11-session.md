learned:

- Review の `?d=` は `toISOString()`（UTC 基準）で書かれていた。JST の朝 9 時以前に URL を生成すると前日の日付が入る。ローカル日付文字列を書くには `getFullYear() / getMonth() / getDate()` 形式が必要
- 正午基準解釈（`T12:00:00` を補完）: タイムゾーンオフセットが最大 ±14h でも YYYY-MM-DD T12:00:00 は当日に留まる。date string の解釈に使えるロバストなパターン
- EntryCard の z-index 体系: 通常 10、選択中 30。重複オーバーレイは 40 が必要
