# コピーライティング・トーンルール

## 基本方針

丁寧だけどカジュアル。敬語は使わず体言止めを基本とする。
ユーザーに寄り添うが、過剰に丁寧にならない。

## 8つのルール

### 1. 敬語禁止（体言止め）

「です/ます」ではなく体言止め。過去形は「〜した」。

| NG                 | OK                                   |
| ------------------ | ------------------------------------ |
| 予定を削除しました | 予定を削除した                       |
| 設定を保存します   | 設定を保存                           |
| 入力してください   | （文脈に応じて省略 or 「〜を入力」） |
| お試しください     | 試して                               |
| 申し訳ございません | （削除、または状況説明のみ）         |

### 2. 専門用語禁止

平易な日本語に置き換える。

| NG                | OK             |
| ----------------- | -------------- |
| クロノタイプ      | あなたのリズム |
| MFAチャレンジ     | 認証コード     |
| reCAPTCHAトークン | 認証           |

### 3. 主語省略

不要な「あなたの」は削除。

| NG                   | OK           |
| -------------------- | ------------ |
| あなたのプロフィール | プロフィール |
| あなたの設定         | 設定         |

### 4. ポジティブ変換

「〜ありません」→「まだ〜がない」+ 次のアクションを示す。

| NG                   | OK                               |
| -------------------- | -------------------------------- |
| データがありません   | まだデータがない                 |
| 通知はありません     | まだ通知がない                   |
| タグがありません     | まだタグがない。最初のタグを作成 |
| 見つかりませんでした | 一致する結果がない               |

### 5. ボタンラベル

- 動詞で始める（「保存」「追加」「削除」）
- 「する」は省略（「追加する」→「追加」）
- destructive は対象を明記（「削除」→「エントリーを削除」「タグを削除」）
- 共通アクション（common.actions）は汎用のまま可。使用箇所で具体化

### 6. エラーメッセージ

何が起きたか + どうすればいいか。

| NG                       | OK                                           |
| ------------------------ | -------------------------------------------- |
| エラーが発生しました     | 問題が起きた。もう一度試して                 |
| タグの作成に失敗しました | タグを作成できなかった。もう一度試して       |
| 同期に失敗しました       | 同期できなかった。ネットワーク接続を確認して |

### 7. 空状態

何を示す場所か + 次のアクション。

| NG                   | OK                                         |
| -------------------- | ------------------------------------------ |
| データがありません   | この週の記録はまだない。カレンダーから追加 |
| イベントがありません | この日はまだ予定がない                     |
| グループがありません | まだグループがない                         |

### 8. プレースホルダー

入力例を示す。「入力してください」は使わない。

| NG                  | OK                     |
| ------------------- | ---------------------- |
| 入力してください    | 例: 朝の Deep Work     |
| 表示名を入力        | 例: Taro               |
| メッセージを入力... | 例: ボタンが反応しない |
| タグ名を入力        | 例: 仕事、勉強         |

## 例外

| 対象          | 理由                                         |
| ------------- | -------------------------------------------- |
| `email.json`  | トランザクションメールは丁寧語を維持         |
| `legal.json`  | 法的テキストは敬語が必要                     |
| `aria.*` キー | スクリーンリーダー用の説明文は現状維持       |
| toast成功通知 | 「〜した」（過去形）で統一。体言止めではない |

## 変換パターン早見表

| パターン         | 変換                               |
| ---------------- | ---------------------------------- |
| 〜しました       | 〜した                             |
| 〜してください   | 文脈依存（省略 or 「〜して」）     |
| 〜します         | 〜する or 体言止め                 |
| 〜されます       | 〜される or 体言止め               |
| 〜できます       | 〜できる                           |
| 〜ございません   | 〜ない                             |
| お〜ください     | 〜して                             |
| 〜に失敗しました | 〜できなかった。（リカバリー追加） |
| 〜がありません   | まだ〜がない（ポジティブ変換）     |
