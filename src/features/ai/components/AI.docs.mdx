# AI

ユーザーのスケジュール・価値観・過去の活動をコンテキストとして組み立て、AIチャットによる時間管理アドバイスとエントリタイトルのサジェストを提供する機能。現在はサーバーサイドのみで構成される。

---

## 概要

| 項目               | 値                                                                        |
| ------------------ | ------------------------------------------------------------------------- |
| 実装範囲           | サーバーサイド専用（クライアントコンポーネントなし）                      |
| プロバイダー       | Anthropic / OpenAI（切り替え可能）                                        |
| 無料枠モデル       | claude-haiku-4-5-20251001（月30リクエスト固定）                           |
| コンテキスト取得   | Promise.all 並列フェッチ（設定・今日のエントリ・直近7日・週間統計・タグ） |
| ツール呼び出し     | Vercel AI SDK v6 `tool()` — 4種類のオンデマンド検索ツール                 |
| タイトルサジェスト | entries テーブルをタイトルでグループ化し、使用頻度・最終使用日でソート    |

---

## コンポーネント構成

現時点でクライアントコンポーネントは存在しない。UIはコール元の feature（entry など）が担当する。

```
server/
├── context-service.ts      buildAIContext() — ユーザーデータ並列取得・AIContext 組み立て
├── prompt-builder.ts       buildSystemPrompt() — AIContext → システムプロンプト文字列
├── tools.ts                createAITools() — Vercel AI SDK ToolSet 生成
├── suggestion-service.ts   SuggestionService.recentTitles() — タイトルサジェスト
├── suggestions-index.ts    SuggestionService の re-export
├── suggestions-router.ts   tRPC suggestionsRouter
├── types.ts                型定義・モデル定数
├── usage-service.ts        createAIUsageService() — 無料枠管理
└── index.ts                サーバー公開 API
```

## 状態管理

AI feature はサーバーサイド専用のため Zustand ストアを持たない。
利用状況（`FreeTierUsage`）は呼び出し元が tRPC 経由で取得する。

---

## Hooks / tRPC

### tRPC ルーター

| エンドポイント             | タイプ | 説明                                              |
| -------------------------- | ------ | ------------------------------------------------- |
| `suggestions.recentTitles` | query  | 最近のユニークタイトル+タグ組み合わせ（最大30件） |

#### `suggestions.recentTitles` 入力スキーマ

| フィールド | 型                       | 説明                                      |
| ---------- | ------------------------ | ----------------------------------------- |
| `search`   | `string?`                | タイトル部分一致フィルター（最大200文字） |
| `limit`    | `number?`                | 取得件数（1〜30、デフォルト20）           |
| `type`     | `'planned' \| 'actual'?` | エントリ種別フィルター                    |

### サーバー公開関数

| 関数                               | 説明                                             |
| ---------------------------------- | ------------------------------------------------ |
| `buildAIContext(supabase, userId)` | AIContext を構築（並列フェッチ）                 |
| `buildSystemPrompt(context)`       | AIContext → システムプロンプト文字列（純粋関数） |
| `createAITools(supabase, userId)`  | Vercel AI SDK ToolSet を生成                     |
| `createAIUsageService(supabase)`   | 無料枠管理サービスを生成                         |

### AIツールセット（`createAITools`）

| ツール名            | 説明                                            |
| ------------------- | ----------------------------------------------- |
| `searchPlans`       | 日付範囲・テキストでエントリ検索                |
| `searchPastEntries` | 過去エントリを充実度スコア込みで検索            |
| `getStatistics`     | 期間別サマリー統計（week / month / year / all） |
| `getTagStats`       | タグ別エントリ件数・最終使用日                  |

## モデル設定

### サポートモデル一覧

| プロバイダー | モデルID                     | 表示名      | 用途                     |
| ------------ | ---------------------------- | ----------- | ------------------------ |
| Anthropic    | `claude-sonnet-4-5-20250929` | Sonnet 4.5  | デフォルト（バランス型） |
| Anthropic    | `claude-haiku-4-5-20251001`  | Haiku 4.5   | 無料枠固定モデル         |
| OpenAI       | `gpt-4o`                     | GPT-4o      | 高性能                   |
| OpenAI       | `gpt-4o-mini`                | GPT-4o mini | OpenAI デフォルト        |

### 無料枠ルール

- 月間上限: **30リクエスト**（`FREE_TIER_MONTHLY_LIMIT`）
- 強制モデル: `claude-haiku-4-5-20251001`（`FREE_TIER_MODEL`）
- カウント方式: `increment_ai_usage` DB関数によるアトミックインクリメント
- リセット周期: 月次（`YYYY-MM` キーで管理）

## AIContext 構造

`buildAIContext()` が組み立てる `AIContext` の主要フィールド：

| フィールド      | 型                                               | 説明                                               |
| --------------- | ------------------------------------------------ | -------------------------------------------------- |
| `values`        | `Record<string, { text, importance }>`           | 12領域の価値観スコア                               |
| `rankedValues`  | `string[]`                                       | 価値観キーワードのランキング（最重要コンテキスト） |
| `aiStyle`       | `'coach' \| 'analyst' \| 'friendly' \| 'custom'` | コミュニケーションスタイル                         |
| `todayEntries`  | `AIContextEntry[]`                               | 今日のエントリー（最大20件）                       |
| `recentEntries` | `AIContextPastEntry[]`                           | 直近7日の過去エントリー（最大10件）                |
| `weeklyMinutes` | `{ planned, actual }`                            | 今週の計画・実績時間（分）                         |
| `timezone`      | `string`                                         | ユーザータイムゾーン                               |
| `chronotype`    | `{ type, enabled }`                              | クロノタイプ設定                                   |
| `tags`          | `{ name, color }[]`                              | アクティブタグ一覧（最大50件）                     |

## DB スキーマ

### ai_usage テーブル

| カラム          | 型          | 説明                   |
| --------------- | ----------- | ---------------------- |
| `id`            | UUID        | PK                     |
| `user_id`       | UUID        | FK → auth.users        |
| `month`         | TEXT        | 年月（`YYYY-MM` 形式） |
| `request_count` | INT         | 当月リクエスト数       |
| `created_at`    | TIMESTAMPTZ | 作成日時               |
| `updated_at`    | TIMESTAMPTZ | 更新日時               |

- **RLS**: `auth.uid() = user_id`
- **ユニーク制約**: `(user_id, month)` — 1ユーザー×1月で1レコード
- **RPC**: `increment_ai_usage(p_user_id, p_month)` — アトミックなカウントアップ

### user_settings テーブル（AI関連カラム）

| カラム                          | 型     | 説明                                     |
| ------------------------------- | ------ | ---------------------------------------- |
| `ai_communication_style`        | TEXT   | コミュニケーションスタイル（`coach` 等） |
| `ai_custom_style_prompt`        | TEXT   | カスタムスタイルのプロンプト文字列       |
| `personalization_values`        | JSONB  | 12領域の価値観データ                     |
| `personalization_ranked_values` | TEXT[] | 価値観キーワードランキング               |
