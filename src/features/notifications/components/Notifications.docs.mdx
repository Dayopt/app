# Notifications

リマインダー通知・AI インサイト通知をユーザーに配信するシステム。個人向けアプリのため、自分の操作に対するイベント通知は不要（Google Calendarと同じ思想）。

---

## 通知タイプ

| タイプ            | 説明                         | アイコン  |
| ----------------- | ---------------------------- | --------- |
| `reminder`        | エントリー開始前リマインダー | Bell      |
| `ai_insight`      | AI インサイト                | Lightbulb |
| `weekly_report`   | 週次レポート                 | Sparkles  |
| `burnout_warning` | バーンアウト警告             | Brain     |
| `energy_insight`  | エネルギーインサイト         | Zap       |

---

## DB スキーマ

### notifications テーブル

| カラム       | 型          | 説明                                       |
| ------------ | ----------- | ------------------------------------------ |
| `id`         | UUID        | PK                                         |
| `user_id`    | UUID        | FK → auth.users                            |
| `type`       | TEXT        | 通知タイプ                                 |
| `entry_id`   | UUID        | 対象エントリーID（FK → entries, nullable） |
| `title`      | TEXT        | 通知タイトル（NOT NULL）                   |
| `data`       | JSONB       | 種別固有のペイロード                       |
| `read_at`    | TIMESTAMPTZ | 既読日時（NULL=未読, 非NULL=既読）         |
| `fire_at`    | TIMESTAMPTZ | 通知発火予定日時（リマインダー等）         |
| `created_at` | TIMESTAMPTZ | 作成日時                                   |

- **RLS**: `auth.uid() = user_id` で自分の通知のみアクセス
- **インデックス**: `(user_id) WHERE read_at IS NULL`（未読通知の高速取得）

### notification_preferences テーブル

| カラム                         | 型      | 説明                         |
| ------------------------------ | ------- | ---------------------------- |
| `enable_browser_notifications` | BOOLEAN | ブラウザ通知ON/OFF           |
| `default_reminder_enabled`     | BOOLEAN | デフォルトリマインダーON/OFF |

## データフロー

```
[Cron Job: daily-insights（毎日）]
       ↓
[Edge Function → Supabase INSERT]
       ↓
[tRPC + TanStack Query キャッシュ更新（refetchInterval: 60s）]
       ↓
[UI更新: ActivityPopover + NotificationItem]
```

## tRPC ルーター

| プロシージャ                                           | タイプ   | 説明                              |
| ------------------------------------------------------ | -------- | --------------------------------- |
| `notifications.list`                                   | query    | 通知一覧取得（entry titleをJOIN） |
| `notifications.unreadCount`                            | query    | 未読数取得                        |
| `notifications.getById`                                | query    | 通知詳細取得                      |
| `notifications.markAsRead`                             | mutation | 個別既読化                        |
| `notifications.markAllAsRead`                          | mutation | 一括既読化                        |
| `notifications.delete`                                 | mutation | 通知削除                          |
| `notifications.deleteAllRead`                          | mutation | 既読通知全削除                    |
| `notificationPreferences.get`                          | query    | 設定取得                          |
| `notificationPreferences.updateBrowserNotifications`   | mutation | ブラウザ通知ON/OFF                |
| `notificationPreferences.updateDefaultReminderEnabled` | mutation | リマインダーON/OFF                |

---

## パフォーマンス

- ページネーション: 50件ずつ取得
- キャッシュ: TanStack Query（60秒自動更新）
- 自動削除: 既読30日後（pg_cron で毎日 03:20 UTC 実行）

---

## セキュリティ

- RLS有効化: 自分の通知のみアクセス
- INSERT は service_role のみ（Edge Function / pg_cron 経由）
