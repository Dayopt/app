# Entries

タスク・予定の統合エントリ機能。タイムボクシング、充実度記録をサポート。

---

## 概要

| 項目     | 値                                                             |
| -------- | -------------------------------------------------------------- |
| 時間位置 | `upcoming` / `active` / `past`（`getEntryState()` で自動判定） |
| 起源     | `planned`（予定）/ `unplanned`（記録のみ）                     |
| 時間指定 | `start_time` + `end_time`（ISO 8601、任意）                    |
| タグ     | `entries.tag_id` → `tags`（1エントリ1タグ）                    |
| 充実度   | `fulfillment_score`（1-3、全 entryState で記録可能）           |

| 要素                        | Planned                    | Unplanned                       |
| --------------------------- | -------------------------- | ------------------------------- |
| 日付                        | 編集可（past 時ロック）    | 常に編集可（past でも移動可能） |

| 記録行                      | 編集可                     | 編集可                          |
| プログレスバー + 差分バッジ | ○                          | ×                               |
| 充実度                      | ○                          | ○                               |
| リマインダー                | ○（past + 未設定は非表示） | ×                               |
| メモ                        | ○                          | ○                               |

```
InspectorTimeSection
├── DateNavigatorRow        日付ナビゲーション

├── TimeDiffBlock           予定 vs 記録の位置ベース差分バー
```

## EntryCard（カレンダー表示カード）

カレンダーグリッド上のエントリ表示ブロック。`@/features/entry/components/card/` に配置。

### 3つの表示モード

| モード    | 条件                                   | ビジュアル                      | 操作                                        |
| --------- | -------------------------------------- | ------------------------------- | ------------------------------------------- |
| **通常**  | `entryState` が `upcoming` or `active` | タグカラー背景 + 実線アクセント | ドラッグ・リサイズ・クリック可              |
| **Past**  | `entryState === 'past'`                | 通常と同じ見た目                | ドラッグ・リサイズ **不可**（クリックのみ） |
| **Draft** | `isDraft === true`                     | `state-selected` オーバーレイ   | ドラッグ・リサイズ **不可**                 |

### 左アクセントストリップ

| origin                  | スタイル                               |
| ----------------------- | -------------------------------------- |
| `planned`（デフォルト） | タグカラーの実線（3px / モバイル 2px） |
| `unplanned`             | タグカラーの点線（5px on / 4px off）   |

### 予定 vs 実績の差分オーバーレイ

`entryState === 'past'` かつ `origin === 'planned'` で `actualStartDate` / `actualEndDate` がある場合に表示。

| 差分                         | 表示                              |
| ---------------------------- | --------------------------------- |
| 未実行（実績が予定より短い） | 斜線ハッチング（`pattern-hatch`） |
| 超過（実績が予定より長い）   | 左アクセント点線 + カード拡張     |

### コンテンツ表示

| 要素                     | 表示条件                               |
| ------------------------ | -------------------------------------- |
| タグ名 or 「タグを追加」 | 常時（tagId 未設定時はフォールバック） |
| 時間範囲                 | `height >= 30px` の場合                |
| リマインダーアイコン     | `reminder_enabled` が `true`           |

### サイズ対応

- 最小高さ: 20px
- `height < 40px`: コンパクトモード（1行表示）
- `height >= 40px`: 通常モード（タグ名 + 時間）

## 「Time waits for no one」原則

- `status` フィールドなし — 時間位置から `getEntryState()` で自動判定
- **Planned** エントリ: past になると日付・予定時間がロック（disabled）、記録行は常に編集可能
- **Unplanned** エントリ: 記録のみなのでロックなし、日付は past でも移動可能
- 充実度は全 entryState で記録可能
- リマインダーは past + 未設定の場合に非表示（もう機能しないため）

## 保存フロー

```
パネル開く
  └── entryId セット → usePlan で取得

ユーザー編集
  ├── タイトル/説明 → 即時保存（autoSave）
  └── 日時変更 → pendingChanges にバッファ
      └── 繰り返しエントリの場合 → スコープダイアログ表示

パネル閉じる
  └── saveAndClose()
      └── updatePlan mutation（楽観的更新）
```
