# Chronotype

ユーザーの睡眠・活動リズム（クロノタイプ）を診断し、カレンダー上に生産性ゾーンを可視化する機能。6問のクイズで lion / bear / wolf / dolphin の4タイプを判定し、時間帯ごとの背景色やボーダーでピーク・ディップを表示する。

---

## 概要

| 項目 | 値 |
|------|-----|
| プリセットタイプ | lion / bear / wolf / dolphin / custom |
| 生産性レベル | warmup / deep / ease / recovery / winddown |
| 表示モード | border / background / both |
| クイズ問題数 | 6問（スコア集計で最高点タイプを判定） |
| 設定保存先 | `user_settings` テーブル（tRPC `userSettings.update` 経由） |
| 対象人口 | lion 15-20% / bear 55% / wolf 15% / dolphin 10% |

---

## コンポーネント構成

```
ChronotypeSettings              設定パネル（診断クイズ起動 + 結果表示）
├── ChronotypeQuiz              6問のステップ式クイズ（回答 → 結果サマリー）
└── TimelineBar                 24時間タイムラインバー（内部コンポーネント）

ChronotypeBackground            カレンダーグリッドの背景色オーバーレイ
                                （pointer-events-none で入力を妨げない）
```

## 状態管理

### Zustand Stores

| Store | 用途 | persist |
|-------|------|---------|
| `useCalendarSettingsStore` | `chronotype` 設定（enabled / type / displayMode / opacity）を保持 | Yes |

クロノタイプ固有の Zustand ストアは存在しない。設定はカレンダー設定ストアに統合されており、`ChronotypeSettings` コンポーネントは `useAutoSaveSettings` フックでデバウンス付き自動保存を行う。

---

## Hooks

### Query

| Hook / API | 用途 |
|------------|------|
| `api.userSettings.get.useQuery()` | DBからクロノタイプ設定を取得（staleTime: 5min） |

### Mutation

| Hook / API | 用途 |
|------------|------|
| `api.userSettings.update.useMutation()` | enabled / type / displayMode / opacity を保存 |

### その他

| Hook | 用途 |
|------|------|
| `useAutoSaveSettings` | 800ms デバウンスで自動保存、成功トースト表示 |

---

## tRPC ルーター

Chronotype 専用ルーターは存在しない。`userSettings` ルーターのエンドポイントを共用する。

| エンドポイント | タイプ | 関連フィールド |
|-------------|-------|---------------|
| `userSettings.get` | query | `chronotype_type`, `chronotype_enabled`, `chronotype_display_mode`, `chronotype_opacity` |
| `userSettings.update` | mutation | `chronotypeEnabled`, `chronotypeType`, `chronotypeDisplayMode`, `chronotypeOpacity` |

---

## クイズ判定ロジック

```
6問 × 4選択肢 → 各選択肢に lion/bear/wolf/dolphin スコアを付与
→ 全問の合計スコアが最大のタイプを返す（同点時は bear をデフォルト）
```

| 質問ID | 内容 |
|--------|------|
| `wakeTime` | 目覚まし不要の自然な起床時間 |
| `morningEnergy` | 午前中のエネルギーレベル |
| `deepFocus` | 最も集中できる時間帯 |
| `afternoonEase` | 午後の眠気パターン |
| `bedTime` | 理想的な就寝時間 |
| `sleepQuality` | 睡眠の質 |

## 生産性ゾーン定義

### プリセット別ピーク時間帯

| タイプ | ウォームアップ | ピーク | ディップ | リカバリー | ウインドダウン |
|--------|-------------|--------|---------|-----------|---------------|
| Lion   | 5–7時 | 7–12時 | 12–14時 | 14–17時 | 17–21時 |
| Bear   | 7–10時 | 10–14時 | 14–16時 | 16–19時 | 19–23時 |
| Wolf   | 10–14時 | 15–21時 | 14–15時 | 21–23時 | 23–1時 |
| Dolphin | 6–8時 | 8–12時 | 12–14時 | 14–17時 | 17–22時 |

### カラートークン

| レベル | Tailwind クラス | CSS変数 |
|--------|---------------|---------|
| warmup | `bg-chronotype-warmup` | `--chronotype-warmup` |
| deep | `bg-chronotype-deep` | `--chronotype-deep` |
| ease | `bg-chronotype-ease` | `--chronotype-ease` |
| recovery | `bg-chronotype-recovery` | `--chronotype-recovery` |
| winddown | `bg-chronotype-winddown` | `--chronotype-winddown` |

背景オーバーレイには淡色版の `bg-chronotype-tint-*` クラスを使用する。

## DBスキーマ

### user_settings テーブル（関連カラムのみ）

| カラム | 型 | 説明 |
|-------|-----|------|
| `chronotype_type` | TEXT | 'lion' / 'bear' / 'wolf' / 'dolphin' / 'custom' |
| `chronotype_enabled` | BOOLEAN | 表示有効フラグ |
| `chronotype_display_mode` | TEXT | 'border' / 'background' / 'both' |
| `chronotype_opacity` | FLOAT | 背景透過度 |
