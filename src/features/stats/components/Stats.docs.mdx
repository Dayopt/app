# Stats

時間記録の統計・分析ビュー。KPIメトリクス、トレンドチャート、パターン分析で自己客観視を支援。

---

## 概要

独立 Feature（`@/features/stats`）として実装。3タブ構成で段階的にデータを深掘りできる。

| タブ                       | ユーザーが得られるもの                                                |
| -------------------------- | --------------------------------------------------------------------- |
| **Review（振り返り）**     | 「今週どうだった？」— 期間ベースの KPI 数値。日/週/月/年で切り替え    |
| **Progress（進捗）**       | 「長期的にどう変わった？」— ヒートマップ + 分布チャートで傾向を可視化 |
| **Insights（インサイト）** | 「AI はどう見ている？」— 数値の裏にある文脈を自然言語で提示           |

---

## タブ詳細

### Review タブ

8つの KPI カードを2行×4列グリッドで表示。前期間との比較トレンド付き。

- Total Time / Avg Fulfillment / Plan Rate / Streak
- Estimation Accuracy / Deep Utilization / Context Switches / Blank Rate

将来的に **Rule Insights**（閾値ベースの自動気づき）をグリッド下に配置予定。

### Progress タブ

累積・長期のトレンドを4つのチャートで表示。

- **年間ヒートマップ**: GitHub の contribution graph 風。1年間の活動量を俯瞰
- **月次トレンド**: 月ごとの記録時間推移。改善/悪化が一目でわかる
- **曜日分布**: どの曜日に活動が集中しているか
- **時間帯分布**: どの時間帯に活動しているか。chronotype との整合確認に

### Insights タブ

LLM が生成した自然言語のインサイト。週1回自動生成（月曜朝）。

- **findings**: 2-4個の発見（カテゴリ別、sentiment カラーコード付き）
- **suggestions**: 1-2個の行動提案（ユーザーの価値観と紐付け）
- **question**: 振り返りの問いかけ

Dayopt の AI は「観察者」。事実を淡々と伝え、モチベーションを上げようとしない。

---

## ヘッダーコントロール

Review / Insights タブ選択時に表示:

- **DateNavigator** — 前後・今日ナビゲーション
- **GranularitySelector** — 粒度切替（日/週/月/年）

## コンポーネント構成

```
StatsPageContent                    タブ管理 + URL ルーティング
├── Review タブ
│   └── StatsView
│       ├── StatsMetricsGrid       8カード KPI（2行×4列）
│       │   └── MetricCard         単一 KPI カード
│       └── RuleInsightList        閾値ベースの気づき（予定）
│
├── Progress タブ
│   └── ProgressView
│       ├── YearlyHeatmap          年間ヒートマップ
│       ├── MonthlyTrendChart      月次トレンド
│       ├── DayOfWeekChart         曜日別分布
│       └── HourlyDistributionChart 時間帯分布
│
└── Insights タブ
    └── InsightsView               ルールベースの発見
        └── DiscoveryList          発見リスト
```
