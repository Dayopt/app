# Layer 3: Schedule & Operations

LLM インサイト生成のスケジュール、コスト、データ要件、エラーハンドリング。

設計の全体像は [L3 LLM Insights](?path=/docs/features-stats-layers-l3-llm-insights--docs) を参照。

---

## スケジュール

Edge Function `generate-reflections` が pg_cron で定期実行し、アクティブユーザーのインサイトを自動生成する。

| 期間 | cron | 実行タイミング | 状態 |
|------|------|-------------|------|
| **週次** | `0 7 * * 1` | 月曜 7:00 UTC | 既存 |
| **月次** | `0 7 1 * *` | 月初 7:00 UTC | 新規 |
| **年次** | `0 7 1 1 *` | 年初 7:00 UTC | 新規 |

**Daily は自動生成しない**。日次粒度選択時は Layer 1 KPI をインライン表示し、「今日の記録を振り返りましょう。週次インサイトは毎週月曜に届きます」と案内。

---

## コスト見積もり

| 期間 | 入力トークン | 出力トークン | コスト/ユーザー | 100ユーザー/月 |
|------|-------------|-------------|----------------|---------------|
| 週次 | ~1,800 | ~500 | ~$0.004 | ~$1.60 |
| 月次 | ~2,000 | ~600 | ~$0.005 | ~$0.50 |
| 年次 | ~2,500 | ~800 | ~$0.006 | ~$0.06 |
| **合計** | | | | **~$2.16/月** |

※ 前回インサイト（+500〜1,000トークン）を含む見積もり。初回生成時はこれより少ない。

インサイトはシステム側のスケジュール実行であり、プロダクトの基本機能。ユーザーの AI クォータは消費しない。

## データ要件とスキップ判定

### pg_cron での処理

Edge Function は全アクティブユーザーに対して走るが、最低要件を満たさなければ生成をスキップする。reflections にレコードを残さない = その週はデータ不足だった、と UI 側で判断できる。

```
エントリ 0件      → スキップ（reflections にレコードなし）
記録日数 1-2日   → スキップ（reflections にレコードなし）
記録日数 3日以上  → インサイト生成
```

データがないのに LLM を呼んでも意味のある出力は出ない。コストも無駄。

### 最低要件

| 要件 | 閾値 |
|------|------|
| 記録日数 | >= 3日 |
| 合計記録時間 | >= 30分 |

## エラーハンドリング

### API エラー時のリトライ

| エラー種別 | 対応 |
|-----------|------|
| Rate Limit (429) | 指数バックオフ（1s → 2s → 4s、最大3回） |
| Server Error (5xx) | 1回リトライ、失敗時はスキップ |
| JSON パース失敗 | そのまま失敗（プロンプトの問題なのでリトライしても無駄） |
| タイムアウト | 30秒で打ち切り、リトライなし |

### 出力バリデーション

LLM の JSON 出力を Zod スキーマでバリデーション。失敗時は `insights` TEXT カラムにフォールバック書き込み（`structured_insights` は null）。

## UI 側の状態表示

### データ量による 3 段階表示

**0件（記録なし）:**

reflections にレコードがない → EmptyState を表示。励ましや「おかえり」は言わない。

```
この週の記録はありません。

前回の記録: 3月3日（月）
[その週のインサイトを見る →]
```

**1-2日分（データ不足）:**

```
この週のデータが十分ではありません。
3日以上の記録があるとインサイトを生成できます。

記録された日: 月曜（2h 30m）
```

**3日分以上:** インサイト生成・表示。

### 未生成（データ十分だが cron 未実行）

```
○月○日に生成予定です ✦
```

## 前回インサイトの活用

生成時に同じ `period_type` の直前の `structured_insights` を取得し、プロンプトに含める。

```sql
SELECT structured_insights FROM reflections
WHERE user_id = $1 AND period_type = $2
ORDER BY period_start DESC LIMIT 1;
```

前回インサイトが存在しない場合（初回生成時）はこのセクションをスキップ。
