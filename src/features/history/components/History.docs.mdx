# History

直近の使用パターンを頻度×鮮度でスコアリングし、サイドバーに「履歴」セクションとして表示する。

---

## 概要

| 項目         | 値                                                |
| ------------ | ------------------------------------------------- |
| 対象期間     | 直近14日間                                        |
| スコアリング | 頻度×鮮度（recency-weighted frequency）           |
| 最大表示数   | 同タグは最頻 duration のみ（上限なし）            |
| duration     | 15分単位にスナップ（`Math.round(min / 15) * 15`） |
| 配置         | サイドバー内、フィルターセクションの下            |

---

## スコアリングロジック

各エントリの `created_at` から鮮度係数を算出し、`tag_id:snapped_duration` をキーに加算。

| 経過日数 | 鮮度係数 |
| -------- | -------- |
| 当日     | 1.0      |
| 1日前    | 0.8      |
| 2-3日前  | 0.6      |
| 4-7日前  | 0.4      |
| 8-14日前 | 0.2      |

`duration_minutes` が未設定の場合は `start_time` / `end_time` から算出。

| Procedure                 | 種別  | 説明                                        |
| ------------------------- | ----- | ------------------------------------------- |
| `history.getRecentBlocks` | Query | 直近14日のエントリを頻度×鮮度で集計して返却 |

---

## データフロー

```
entry_tags + entries（直近14日）
  ↓ Supabase join
duration 15分スナップ
  ↓
tag_id:duration をキーにスコア加算（鮮度係数）
  ↓
スコア降順 → 同タグは最頻 duration のみ
  ↓
RecentBlocks で表示
```
