# Elevation（高さ）

UI 要素の z 軸上の位置。surface色 + shadow + border のセットで表現する。shadow 単体ではなく、3つの組み合わせ。

---

## 設計原則

**Light:** shadow が奥行きの主役。面色差は補助。
**Dark:** 面色差が主役。shadow は補助。

この逆転が elevation 設計の核心。Light と Dark で「浮いて見える」仕組みが違う。

---

## Elevation レベル（4段階）

| Level   | Surface         | Shadow        | Border                 | 用途                      |
| ------- | --------------- | ------------- | ---------------------- | ------------------------- |
| Sunken  | `bg-container`  | none          | `border-border`        | sidebar, footer           |
|         | `bg-muted`      | none          | —                      | input, well               |
| Base    | `bg-background` | none          | —                      | ページ地                  |
| Raised  | `bg-card`       | `shadow-sm`   | `border-border-subtle` | カード, セクション        |
| Overlay | `bg-card`       | `shadow-card` | `border-border-subtle` | dropdown, popover, dialog |

### Shadow の値

| Token         | Light                                       | Dark                       | 用途                             |
| ------------- | ------------------------------------------- | -------------------------- | -------------------------------- |
| `shadow-xs`   | 1px 2px(0.04)                               | 1px 2px(0.14)              | form control（input, select 等） |
| `shadow-sm`   | ring(0.03) + 1px 3px(0.03)                  | ring(0.03) + 1px 4px(0.18) | Raised（card, section）          |
| `shadow-card` | ring(0.03) + 1px 2px(0.04) + 4px 16px(0.05) | ring(0.04) + 2px 8px(0.25) | Overlay（dropdown, popover 等）  |

`shadow-xs` は Elevation 4段階とは独立した form control 専用トークン。
Sunken と Base は shadow なし。Raised と Overlay だけが Elevation shadow を持つ。

---

## なぜ 6段階 → 4段階か

旧: `shadow-none` / `xs` / `sm` / `md` / `lg` / `xl` の6段階
新: Sunken / Base / Raised / Overlay の4段階

6段階だと「この dropdown は shadow-lg? shadow-xl?」と毎回迷う。4段階なら判断は明確:

- 背景に沈むか？ → **Sunken**
- 地面か？ → **Base**
- 浮くか？ → **Raised**
- 最前面か？ → **Overlay**

Color ページの Surface トークンと 1:1 で対応するので覚えることが増えない。

---

## Dark mode での見え方

Light では Raised と Base の区別は主に shadow で見える。Dark では shadow がほぼ見えないので、面色差で区別する。

| Level   | Light L     | Dark L      |
| ------- | ----------- | ----------- |
| Sunken  | 0.95 / 0.94 | 0.15 / 0.25 |
| Base    | 0.97        | 0.18        |
| Raised  | 0.99        | 0.22        |
| Overlay | 0.99        | 0.22        |

Light の Raised / Overlay は純白（1.00）ではなく paper-99。純白は紙より「発光」に見えるため使わない（Colors の Paper スケール参照）。

Dark の Raised と Overlay は同じ surface 色。違いは shadow の強さと z-index。

---

## z-index

| Level   | z-index | 備考                                |
| ------- | ------- | ----------------------------------- |
| Sunken  | auto    | 通常フロー                          |
| Base    | auto    | 通常フロー                          |
| Raised  | auto    | 通常フロー（shadow で浮いて見える） |
| Overlay | 50+     | ページの上に重なる要素              |

z-index は Overlay 以上でのみ使う。Sunken / Base / Raised は z-index を指定しない。

---

## 実装例

### Raised: カード

```tsx
<div className="bg-card border-border-subtle rounded-lg border p-4 shadow-sm">...</div>
```

### Overlay: ドロップダウン

```tsx
<div className="bg-card border-border-subtle shadow-card z-50 rounded-lg border p-2">...</div>
```

### Overlay: モーダル

```tsx
<div className="bg-overlay fixed inset-0 z-50" />  {/* scrim */}
<div className="bg-card border-border-subtle rounded-2xl border shadow-card p-6 z-50">
  ...
</div>
```

### Sunken: サイドバー

```tsx
<aside className="bg-container border-border border-r">...</aside>
```
