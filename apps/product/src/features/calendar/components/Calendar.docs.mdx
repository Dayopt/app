# Calendar

時間管理の中核ビュー。エントリをタイムグリッド上に表示し、ドラッグ&ドロップで直感的に操作する。

エントリカード（`TimeblockCard`）は `@/features/timeblock` に定義。カレンダーはそれを利用して描画する。

---

## ビュー一覧

| ビュー        | 説明                   | コンポーネント |
| ------------- | ---------------------- | -------------- |
| **Day**       | 1日のタイムグリッド    | `DayView`      |
| **Week**      | 7日間のタイムグリッド  | `WeekView`     |
| **Multi-Day** | 2〜9日間のカスタム表示 | `MultiDayView` |

ビュー切替は `ViewSwitcherList` コンポーネントで行い、`CalendarNavigationContext` で状態管理。
Review / Diff は view ではなく Calendar の単一 panel slot に表示する。Storybook 上の panel 表示は `Product/Features/Review` が所有し、Calendar は時間軸表示だけを扱う。


## 状態管理

### Zustand Stores

| Store                    | 用途                                 | persist |
| ------------------------ | ------------------------------------ | ------- |
| `useCalendarFilterStore` | タイプ/タグのフィルター              | Yes     |
| `useCalendarDragStore`   | ドラッグ元・ゴースト・プレビュー時間 | No      |
| `useCalendarScrollStore` | スクロール位置同期                   | No      |

### Context

| Context                     | 用途                                    |
| --------------------------- | --------------------------------------- |
| `CalendarNavigationContext` | 日付・ビュー・panel・ナビゲーション操作 |
| `CalendarGridProvider`      | グリッド計算の共有                      |

---

## ドラッグ & ドロップ

- **技術**: `@dnd-kit/core`
- **ソース**: カレンダーグリッド、アサイド
- **ターゲット**: タイムグリッドセル
- **センサー**: PointerSensor（8px閾値）、TouchSensor（250ms遅延）
- **機能**: ドラッグプレビュー、時間計算、モバイルハプティクス

---

## フィルター

| フィルター | 説明                         |
| ---------- | ---------------------------- |
| タイプ別   | エントリタイプの表示切替     |
| タグ別     | 階層対応のマルチタグフィルタ |
| 未タグ     | タグなしアイテムの表示トグル |

`useCalendarFilterStore` で管理、localStorage に永続化。

---

## コンテキストメニュー

| メニュー               | トリガー                 | アクション                       |
| ---------------------- | ------------------------ | -------------------------------- |
| `EventContextMenu`     | エントリカード右クリック | 振り返り、コピー、削除、状態操作 |
| `EmptyAreaContextMenu` | 空エリア右クリック       | プラン作成、レコード作成         |

---

## データ同期

`refetchOnWindowFocus`（TanStack Query）でタブ切り替え時にデータを自動再取得。

---

## DB テーブル

| テーブル  | 用途                                                       |
| --------- | ---------------------------------------------------------- |
| `entries` | エントリデータ（タイトル、時間、タグ、ステータス等を統合） |
| `tags`    | マスタータグ（`entries.tag_id` で参照）                    |

---

## キーボード操作

- ビュー切替、日付ナビゲーション、プラン選択
- 選択中の Plan / Record をコピーし、同じ種別の独立した Timeblock として貼り付け
- 週末トグルショートカット
- Escape でキャンセル
