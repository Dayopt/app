# Tags

Plan / Recordを分類するtag component群。Storybookではhierarchy、color / icon、drag、rename、merge、delete confirmationの表示状態を確認する。

## Component states

- flat / parent-child tree
- selected / unselected / hovered / dragging
- color and icon picker
- create / rename / merge / delete dialog
- empty and long-name state

tagの階層・1 block 1 tag等のproduct contractはroot `docs/product/specs/tags.md`を参照する。DB schemaやtRPC endpoint catalogはStorybookへ複製しない。
