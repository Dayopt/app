# Contact

ログイン中のユーザーが、Product内からバグ報告・機能要望・質問を送る問い合わせ機能。ProductionではResendを通して`support@dayopt.app`へ配送する。

---

## 概要

| 項目       | 値                                                        |
| ---------- | --------------------------------------------------------- |
| カテゴリ   | bug / feature / question / other                          |
| メッセージ | 最小10文字 / 最大5000文字                                 |
| 送信先     | `support@dayopt.app`（server固定）                        |
| Reply-To   | 認証済みユーザーのemail                                   |
| レート制限 | Upstash（user単位 + Product全体）                         |
| 認証       | ログイン必須（`protectedProcedure`）                      |
| 環境情報   | appVersion / OS / browser / timezone / languageを自動収集 |

Preview / DevelopmentはResend credentialが存在しても実配送を拒否する。

---

## コンポーネント構成

```text
ContactDialog                   Container（tRPC mutation + 環境収集 + payload ID）
└── ContactDialogContent        Presentational UI（tRPC非依存、Storybook対応）
                                ├── RadioGroup  カテゴリ選択（2列グリッド）
                                └── Textarea    メッセージ入力（最大5000文字）
```

`ContactDialog`がtRPC、環境情報、i18n labelを収集し、`ContactDialogContent`へpropsとして渡す。失敗時は入力を保持する。

---

## 再送とidempotency

- 同じカテゴリ・本文・環境情報の再送では同じ`submissionId`を使う
- 内容を編集した後は新しい`submissionId`を作る
- serverは`submissionId`からProduct専用のResend idempotency keyを作る
- 成功時またはdialogを閉じた時に保持中のIDを破棄する

---

## tRPC mutation

| endpoint         | input                                                | output              |
| ---------------- | ---------------------------------------------------- | ------------------- |
| `contact.submit` | category、message、environment、`submissionId: uuid` | `{ success: true }` |

serverは認証済みuserから氏名とemailを取得する。From、To、件名、source tagはclient inputを使わず固定し、emailは改行・カンマを拒否してReply-Toだけに使う。

---

## エラーとprivacy

- rate limit、設定不足、provider error、timeoutでは成功表示にしない
- 問い合わせ本文、氏名、email、provider response bodyをlogger / Sentryへ記録しない
- Resend failure webhookはProduct固有の署名secretとsource tagで検証し、同じeventを重複処理しない
- 実際の受信・返信・保持運用は`docs/operations/contact-email.md`を正本とする
