# Timeblock（Plan / Record）

Plan / Recordのcard、editor、inspector、record action component群。Storybookではentity kindと時間状態ごとの見た目・操作可能性を確認する。

## Visual states

| 対象           | 主な状態                                                       |
| -------------- | -------------------------------------------------------------- |
| TimeblockCard  | Plan / Record、upcoming / active / past、selected、dragging    |
| Inspector      | desktop popover / mobile drawer、time locked、validation error |
| Editor         | Plan / Record destination表示、conflict、submitting            |
| Record actions | そのまま記録、日単位の一括確定、pending                        |

- destination chipは選択UIではなく、入力時間から導出された状態表示
- past Planは時間fieldをdisabledにし、内容訂正とrecord actionは残す
- product rule、DB、RPCはStorybookに複製しない

正本はroot `docs/product/specs/plan-record.md`を参照する。
