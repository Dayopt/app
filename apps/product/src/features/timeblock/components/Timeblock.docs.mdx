# Timeblock（Plan / Record）

Plan / Recordのcard、editor、inspector、record action component群。Storybookではentity kindと時間状態ごとの見た目・操作可能性を確認する。

## Visual states

| 対象           | 主な状態                                                            |
| -------------- | ------------------------------------------------------------------- |
| TimeblockCard  | Plan / Record、upcoming / active / past、selected、dragging         |
| Inspector      | desktop popover / mobile drawer、time locked、validation error      |
| Editor         | 未来Plan、過去Planのtime locked、Record、全体disabled               |
| Record actions | そのまま記録、日単位の一括確定、pending                             |
| Relationships  | Planの関連Record一覧、Recordの元Plan、loading / error / unavailable |

- Inspectorで開いたPlan / Recordは時間編集で暗黙変換しない
- past Planは時間fieldをdisabledにし、内容訂正とrecord actionは残す
- 「そのまま記録」のpendingは、最新のタグ・メモ保存からRecord作成まで継続する
- Plan / Recordの関係はraw IDではなくタグと日時で示し、行選択で同じInspectorの対象を切り替える
- product rule、DB、RPCはStorybookに複製しない

## コンポーネント構成

```
TimeblockInspector                    Inspector シェル（PC: FloatingPopover / Mobile: Drawer）
└── TimeblockInspectorForm            Plan / Record 共有の編集フォーム
    ├── TagRow                        タグ選択 + 共通メニュー（振り返り / コピー / 削除等）
    ├── DateTimeSection / メモ        自動保存される共有編集フィールド
    └── TimeblockRelationshipSection  関連Record / 元Planの人間向け表示と詳細切替

TimeblockEditor                       インライン作成エディタ（タグパレット等から）
TimeblockRecordActions                記録導線（ワンタップ「そのまま記録」/ ConfirmDayButton）
TimeblockCard                         カレンダー表示カード（ドラッグゴースト等）
```

カレンダー側の 2 レーン描画は `features/calendar` の `TwoLaneTimeblockRenderer` +
`PlanLaneCard` / `RecordLaneCard` が担う（Plan レーン = アウトライン、Record レーン = 塗り）。

## サーバー層

| モジュール                          | 責務                                                           |
| ----------------------------------- | -------------------------------------------------------------- |
| `plans-router` / `plan-service`     | Plan CRUD、skip / unskip、ワンタップ記録、一括「この日を確定」 |
| `records-router` / `record-service` | Record CRUD（`plan_id` 紐づけ / 予定外）                       |
| `router-index`（statistics）        | 統計 procedure（`api.statistics.*`）。実体は TS service        |
| `statistics-service`                | 実績 = records、予定 = plans、予実比較 = join の集計           |
| `timeblock-overlap-service`         | 同レーン重なりの事前チェック                                   |

## 状態管理・Hooks

| 対象                                           | 用途                                               |
| ---------------------------------------------- | -------------------------------------------------- |
| `useTimeblockInspectorStore`                   | Inspector 開閉、対象 id / kind（plan / record）    |
| `useTimeblockWriteMutations`                   | Plan / Record の作成・更新・削除（楽観的更新付き） |
| `useCoalescedTimeblockSave`                    | 自動保存の直列化、最新差分の集約、記録前barrier    |
| `useTimeblockRecordMutations`                  | ワンタップ記録 / この日を確定                      |
| `useInspectorURLSync` / `useInspectorKeyboard` | URL 同期・キーボード操作                           |

コピーは表示内容と Plan / Record の種別だけを保持する。`id` / `plan_id` は保持せず、貼り付け時は同じ種別の独立した Timeblock を作る。

---

## 過去 Plan の扱い

- 予定時間の変更（移動・リサイズ）: 不可
- タグ・メモの訂正: 可
- 過去日付への新規 Plan 追加: 不可（実際にやったことは予定外の Record へ）
- ワンタップ記録 / skip / 削除: 可

正本は `docs/product/specs/plan-record.md` を参照する。
