# Data Flow

Calendar Review panel のデータ取得・変換・表示のパイプライン。

---

## 全体像

```
PostgreSQL RPC 関数
  → tRPC ルーター (entry feature)
    → TanStack Query (並列取得・自動キャッシュ)
      → 純粋計算関数
        → Calendar panel UI
```

Review の補助 insight はルールベースで client-side 評価:

```
TanStack Query (getStatsPageData / getTimePL)
  → review domain / presentation derivers
    → WeeklyReflectionPanel
```

---

## tRPC エンドポイント

**ルーター**: `apps/product/src/features/entry/server/statistics-summary-router.ts`

| エンドポイント     | Consumer            | 説明                                       |
| ------------------ | ------------------- | ------------------------------------------ |
| `getStatsPageData` | `useReviewPageData` | 週次 Review panel の overview / trend data |
| `getTimePL`        | `useTimePLData`     | Time P/L 用の planned / actual / diff data |

Reflection は `getStatsPageData.estimationAccuracy` と `getStatsPageData.blankRate` を直接使う。確認済み率（#1333）と skip 週次集約（#1289 `skipped_at`）は次の data 接続で `WeeklyReflectionPanel` の props へ入れる。

Diff は Calendar の表示中 entries から `computeCalendarDayDiffs` で導出する。day view では 1 日、multi-day view では表示範囲全体を bounds にする。Calendar は `entryId` action に戻す adapter を持ち、表示は Review / Diff の `ReviewDiffPanel` が所有する。

---

## 状態管理

### useReviewFilterStore (Zustand)

| State         | 型       | 説明                 |
| ------------- | -------- | -------------------- |
| `granularity` | `'week'` | 表示粒度             |
| `currentDate` | `Date`   | ナビゲーション基準日 |

### URL 状態

Calendar URL の `panel=review` と `reviewTagId` で表現する。期間は Calendar の `date` search param を使う。

---

## キャッシュ戦略

- Reflection: TanStack Query の staleTime でキャッシュ。週・日付の組み合わせがキャッシュキー
- Diff: Calendar view data から同期的に導出し、追加 RPC は呼ばない
