# Layer Architecture

Review panel の技術的な分層設計。Reflection と Diff を同じ Review 所有の panel segment として扱う。

---

## 2 segment model

```
Reflection  週次 Review。所見、KPI、Time P/L、見積バイアス、スキップ、空白を1画面で表示
Diff        表示範囲差分。Calendar entries から予定外・未実施・移動・長さ変更を表示
```

### Data vs Panel Segment

data source と panel segment は**直交する**概念。

|                       | Reflection                                      | Diff                      |
| --------------------- | ----------------------------------------------- | ------------------------- |
| **RPC**               | `getStatsPageData` / `getTimePL`                | なし                      |
| **Client derivation** | Time P/L derivers                               | `computeCalendarDayDiffs` |
| **UI**                | `CalendarReviewPanel` / `WeeklyReflectionPanel` | `ReviewDiffPanel`         |

runtime では Reflection と Diff がまだ別 `panel` state だが、表示 component は Review が両 segment を所有する。

---

## Reflection

週次 Review の compact panel。LLM は使わず、既存 RPC と純粋 deriver で表示する。

- **所見**: 見積バイアス、スキップ、空白から最上位 signal を 1-2 文で出す
- **KPI**: 記録時間、計画達成率、確認済み率（#1333 接続前は差分 KPI）
- **Time P/L**: `deriveStatement` / `deriveAccuracy` / `deriveBarComparison`
- **見積バイアス**: `getStatsPageData.estimationAccuracy`
- **スキップ**: #1289 の `skipped_at` を週次集約して後続接続
- **空白**: `getStatsPageData.blankRate`
- **計算場所**: `features/timeblock` の summary RPC + `features/review/domain`
- **AI 依存**: なし
- **対象**: 全ユーザー（Free 含む）

詳細な catalog は現行 Storybook taxonomy では個別 story に集約する。

---

## Diff

Calendar の表示範囲における予定と実績の差分を Calendar entries から導出する。

- **Summary**: planned / actual / diff / unplanned / missed
- **List**: unplanned / missed / shifted / resized
- **計算場所**: `features/calendar/lib/day-diff.ts`
- **AI 依存**: なし
- **対象**: day view / week view / 2〜9day multi-day view

詳細な catalog は現行 Storybook taxonomy では個別 story に集約する。

---

## Not In V1

- Analytics panel は v1 の主要構成に含めない。
- LLM insight は扱わない。
- Diff の diff 導出と Calendar entry action adapter は Calendar 側に残す。

---

## Feature Boundary

```
entry feature     → DB 集約（RPC 呼び出し）を所有
review feature    → 表示ロジック・UIを所有
settings feature  → AI 設定（communication style, values）を所有
supabase/functions/ → Edge Function（プラットフォーム基盤）
```

Feature 間の直接 import は公開 API 経由に限定する。Diff 表示は `ReviewDiffPanel` が所有し、Calendar は render slot に diff payload と `timeblockId` action を渡す。
