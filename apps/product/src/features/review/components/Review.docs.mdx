# Review

Calendar の contextual panel として表示する振り返り UI。週次サマリー、Time P/L、タグ別差分、選択タグ詳細で「実際に何が起きたか」を提示する。

---

## 概要

`@/features/review` は集計 domain / hooks / panel UI を持つ。表示先は Calendar shell の panel slot で、正規 URL は `/calendar/week?date=YYYY-MM-DD&panel=review`。

Review tag detail は `reviewTagId` search param で表し、Calendar の tag filter state とは分ける。

---

## 表示要素

上から順に:

- **CalendarReviewPanel** — Calendar panel slot 用の compact Review
- **Time P/L summary** — 予定 / 実績 / 差分 / 精度の要約
- **Tag variance list** — タグ別の予実差分
- **Selected tag detail** — `reviewTagId` で選択されたタグの compact detail

---

## URL 状態

- Review: `/calendar/week?date=YYYY-MM-DD&panel=review`
- Review tag detail: `/calendar/week?date=YYYY-MM-DD&panel=review&reviewTagId=...`
- Day diff: `/calendar/day?date=YYYY-MM-DD&panel=diff`
- Analytics: `/calendar/{view}?date=YYYY-MM-DD&panel=analytics`

---

## コンポーネント構成

```
CalendarViewClient
└── CalendarController
    └── panelRail
        └── CalendarReviewPanel
            ├── weekly metrics
            ├── tag variance rows
            └── selected tag detail
```
