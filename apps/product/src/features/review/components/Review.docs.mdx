# Review

Calendar の contextual panel として表示する振り返り UI。週次サマリー、Time P/L、タグ別差分、選択タグ詳細で「実際に何が起きたか」を提示する。

---

## 概要

`@/features/review` は集計 domain / hooks / panel UI を持つ。表示先は Calendar shell の panel slot で、現行 URL は `/week?date=YYYY-MM-DD&panel=review`。

Review tag detail は `reviewTagId` search param で表し、Calendar の tag filter state とは分ける。

---

## Storybook 構成

- **Reflection** — 週次 Review。`CalendarReviewPanel`、Time P/L、タグ別差分、選択タグ詳細を含む
- **Diff** — 日次差分。予定外、未実施、移動、長さ変更を右パネルで扱う
- **Shared** — Review 内で使う補助 UI

## 表示要素

Reflection は上から順に:

- **CalendarReviewPanel** — Calendar panel slot 用の compact Review
- **Time P/L summary** — 予定 / 実績 / 差分 / 精度の要約
- **Tag variance list** — タグ別の予実差分
- **Selected tag detail** — `reviewTagId` で選択されたタグの compact detail

Diff は日次の予定と実績の差分を表示する。`ReviewDiffPanel` は Calendar 内部型を受け取らず、Calendar 側で導出した diff payload と `entryId` action だけを受ける。

---

## URL 状態

- Review: `/week?date=YYYY-MM-DD&panel=review`
- Review tag detail: `/week?date=YYYY-MM-DD&panel=review&reviewTagId=...`
- Day diff: `/day?date=YYYY-MM-DD&panel=diff`

---

## コンポーネント構成

```
CalendarViewClient
└── CalendarController
    └── panelRail
        └── CalendarReviewPanel
            ├── weekly metrics
            ├── tag variance rows
            └── selected tag detail

CalendarController
└── sideRail
    └── ReviewDiffPanel
        ├── daily diff summary
        └── diff rows
```
