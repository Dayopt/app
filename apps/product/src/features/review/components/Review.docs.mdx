# Review

Calendarの右panelに表示するReflection / Diff component群。Storybookではpanel幅、loading / empty / populated state、差分rowのvisual hierarchyを確認する。

## Story ownership

- **Reflection** — `CalendarReviewPanel`、週次summary、tag detail
- **Diff** — `ReviewDiffPanel`、summary、未記録・skip・予定外等のrow
- **Shared** — Review内だけで使うindicatorとinsight

Review componentはCalendarのrender slotへ配置されるが、component、story、visual terminologyはReview featureが所有する。Calendar Storyへpanel UIを複製しない。

URL・期間・data ownershipはroot `docs/product/specs/review.md`と`docs/engineering/architecture.md`を参照する。
