# Review

Calendar の contextual panel として表示する振り返り UI。週次 Reflection と表示範囲 Diff を同じ Review 所有の panel segment として扱う。

---

## 概要

`@/features/review` は集計 domain / hooks / panel UI を持つ。表示先は Calendar shell の panel slot で、現行 URL は `/week?date=YYYY-MM-DD&panel=review`。

Review tag detail は `reviewTagId` search param で表し、Calendar の tag filter state とは分ける。

---

## Storybook 構成

- **Reflection** — 週次 Review。`WeeklyReflectionPanel` を中心に、所見、KPI、Time P/L、見積バイアス、スキップ、空白、選択タグ詳細を含む
- **Diff** — Calendar の表示範囲差分。予定外、未実施、移動、長さ変更を右パネルで扱う
- **Shared** — Review 内で使う補助 UI

## 表示要素

Reflection は上から順に:

- **CalendarReviewPanel** — Calendar panel slot 用の data shell
- **WeeklyReflectionPanel** — 所見、KPI、Time P/L、見積バイアス、スキップ、空白の 1 画面 Reflection
- **Time P/L summary** — 予定 / 実績 / 差分 / 精度の要約
- **Selected tag detail** — `reviewTagId` で選択されたタグの compact detail

Diff は表示範囲内の予定と実績の差分を表示する。`ReviewDiffPanel` は Calendar 内部型を受け取らず、Calendar 側で導出した diff payload と `timeblockId` action だけを受ける。

---

## URL 状態

- Review: `/week?date=YYYY-MM-DD&panel=review`
- Review tag detail: `/week?date=YYYY-MM-DD&panel=review&reviewTagId=...`
- Diff: `/day?date=YYYY-MM-DD&panel=diff` / `/week?date=YYYY-MM-DD&panel=diff` / `/3day?date=YYYY-MM-DD&panel=diff`

---

## コンポーネント構成

```
CalendarViewClient
└── CalendarController
    └── panelRail
        └── CalendarReviewPanel
            ├── WeeklyReflectionPanel
            ├── weekly metrics
            ├── estimation bias rows
            └── selected tag detail

CalendarController
└── sideRail
    └── ReviewDiffPanel
        ├── daily diff summary
        └── diff rows
```
