# ビジュアルディレクション

Dayoptのマーケティングサイト・LPのビジュアル方向性を定義する。

---

## 1. デザイン原則

ブランドパーソナリティ（[messaging.md](?path=/docs/strategy-brand-messaging--docs) §7）のビジュアルへの翻訳:

| パーソナリティ       | ビジュアルでの表現                                               |
| -------------------- | ---------------------------------------------------------------- |
| 静かに自信がある     | 余白を多く、要素を少なく。力強いタイポグラフィで語る             |
| 知的だけど冷たくない | モノトーン基調に温かみのあるアクセント。過度にクリニカルにしない |
| 余白がある           | 情報密度を低く保つ。呼吸のあるレイアウト                         |

---

## 2. タイポグラフィ

### 書体

**Inter**（プロダクトUIと統一）

- サンセリフで静かに語る。装飾的な書体は使わない
- ウェイト使い分け:
  - **Semi-Bold / Bold** — ヘッドライン、セクションタイトル
  - **Regular** — 本文
  - **Light** — サブテキスト、補足情報

### サイズ感

- ヘッドラインは大きく、余白を多く取る
- 本文はゆったりとした行間（line-height: 1.7〜1.8）
- モバイルでも読みやすいサイズを維持（min 16px）

---

## 3. カラー

### 方向性

派手な原色ではなく**抑えたトーン**。アクセントに**1色だけ意志の強さ**を感じる色。

### 基本構成

| 役割       | 方向性                   | 備考                                 |
| ---------- | ------------------------ | ------------------------------------ |
| 背景       | ホワイト〜ごく淡いグレー | クリーンで広がりのある印象           |
| テキスト   | ダークグレー〜チャコール | 真っ黒は避ける（硬すぎる）           |
| アクセント | [UNDECIDED]              | 1色のみ。CTA・ハイライトに使用       |
| セカンダリ | ネイビーブルー系         | 知性と信頼。既存ブランドカラーの系譜 |

### アクセントカラーの選定基準 [UNDECIDED]

- ブランドパーソナリティ（「静かに自信がある」）と合致するか
- CTA として十分なコントラストがあるか
- ダーク/ライトモード両方で機能するか
- プロダクトUIのカラーシステムとの調和

---

## 4. イメージ戦略

### 方向性

| 選択肢                                        | 評価   | 備考                                            |
| --------------------------------------------- | ------ | ----------------------------------------------- |
| **プロダクトスクリーンショット/モックアップ** | 推奨   | 「実際にこう見える」の説得力。LP戦略でも推奨    |
| 抽象イラスト                                  | 非推奨 | 汎用的になりがち。Dayoptらしさが出にくい        |
| 写真（人物）                                  | 未定   | 「1人の作業」の静かなシーンなら合うかもしれない |
| 使わない（タイポグラフィのみ）                | 検討中 | ミニマルだが訴求力が弱くなるリスク              |

### Proof セクション

LPのProofセクションでは実際のプロダクト画面を使用する。モックアップではなく、できる限りリアルなスクリーンショットを採用。

---

## 5. 全体のトーン

- **クリーン**: 余計な装飾を排除
- **落ち着いている**: アニメーションは控えめ、必要な場所だけ
- **プロフェッショナル**: SaaSプロダクトとしての信頼感
- **温かみ**: 完全な無機質にはしない。アクセントカラーや微妙なグラデーションで「人の気配」を残す
