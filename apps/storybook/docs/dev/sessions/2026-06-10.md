decisions:

- ReviewView を粒度別 dispatcher に縮小（442行 → 51行）し、DailyReview / WeeklyReview / MonthlyReview / YearlyReview を独立コンポーネントに分離。粒度ごとに「別の問いに答える」設計原則に従い、composition を完全に切り分ける
- 週次ビューを所見（InsightSlot）+ KPI 行 + Time P/L 主役構成に刷新。「記録合計 + トップタグ」を KPI 行に降格させ、計画 vs 実績（Time P/L）を最上位セクションに据える
- 日次ビューを DayTimelineComparison（計画 vs 実績タイムライン）を主軸に構成し、充実度採点 UI を追加してインラインで評価を記録できるようにする
- 所見（InsightSlot）に信頼性ガードを追加。記録数が閾値以下の期間は断言せず、数字のみ表示する（copywriting.md の「沈黙も人格の一部」に従う）
- 週のリズム（曜日別分布）を週開始曜日対応（settings から取得）に変更し、前期間ゴースト（比較用グレー棒）を追加
- URL パラメータ（?g=&d=）の復元を SSR prefetch と同期。HydrationBoundary との整合を明示的に管理し deep link で正しい粒度・日付のページが表示される

conventions:

- ReviewView は dispatcher 専用（データ取得ロジックなし）。データ取得は各粒度コンポーネントが直接 hooks を呼ぶ
- InsightSlot の confidence prop で信頼性ガードを制御。LOW の場合は表示をスキップ
