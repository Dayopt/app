learned:

- Supabase の db push は先行マイグレーションがデータ不整合で失敗すると後続も全てブロックされる
- Zustand ストアに computed property がないため、DB削除したカラムの値はストアに残しつつ sync 時に導出する方式が最も影響範囲が小さい
- PostToolUse フォーマッターフックが Edit 後にファイルを変更するため、連続編集時に stale file エラーが頻発する → 編集前に毎回 Read が必要
