# Create Plans

Plans are the core of timeboxing in Dayopt. A Plan is something you intend to do — a meeting, a focused work session, an errand. You put it on the calendar first, so you can see how your day is spent.

## Creating a Plan

There are four ways to create a Plan.

| Method                    | How                                                    |
| ------------------------- | ------------------------------------------------------ |
| **Click on the calendar** | Click an empty time slot                               |
| **Drag on the calendar**  | Drag across a time range to set the start and end time |
| **`C`**                   | Create a block                                         |
| **`Shift+C`**             | Create a 15-minute block starting at the current time  |

The Inspector opens when the Plan is created. Type a title and it saves as you go.

## Editing a Plan

Click a Plan on the calendar to open the **Inspector**. You can edit these fields:

- **Title** — saves automatically as you type
- **Date** — move the Plan to a different date
- **Time** — adjust the start and end (duration is shown automatically)
- **Tag** — one tag per block
- **Note** — write down what the Plan is about

Inside the Inspector, use `↑` / `k` and `↓` / `j` to move between blocks. Press `Escape` to close it.

## Drag and Drop

- **Move** — drag a Plan to a different time slot
- **Resize** — drag the bottom edge to change the end time

Press `Escape` during a drag to cancel.

## Tagging a Plan

Each Plan takes one tag. Sort your time by how you spend it — "Deep work", "Meeting", "Admin" — and you can see where the hours went when you review.

A block holds one tag. You cannot add more than one.

## Completing a Plan

When you finish, click **"Mark complete"** in the Inspector. **"Mark incomplete"** puts it back.

**"Complete + Create Timeblock"** marks the Plan done and creates another block with the same details.

If you did not do it, use **"Skip"**. Skipped Plans drop out of your totals but stay in your history. You can **"Undo skip"** later.

## Linking a Record

A Record is the time you actually spent. From the Inspector, use **"Link Record"** to pick an existing Record, or **"Add Record"** to create one.

Time you did not plan shows up as **"Unplanned"**. Use **"Restore plan"** in the Inspector to treat it as a Plan again.

The Inspector shows the gap between plan and record under "Diff" and "Time progress".

## Duplicating a Plan

Open the Inspector menu and select **"Duplicate"** to create another Plan with the same details. The same menu can copy a link to the Plan.

## Switching the sidebar

The sidebar has two tabs: **Calendar** and **List**. The List tab shows your Plans in a list.

## Keyboard Shortcuts

| Shortcut          | Action                              |
| ----------------- | ----------------------------------- |
| `C`               | Create a block                      |
| `Shift+C`         | Create a block at the current time  |
| `Escape`          | Close the Inspector / cancel a drag |
| `↑` or `k`        | Previous block                      |
| `↓` or `j`        | Next block                          |
| `Cmd+C` / `Cmd+V` | Copy / paste                        |
| `Delete`          | Delete the selected block           |

On Windows and Linux, use `Ctrl` instead of `Cmd`. Press `Shift+?` to see the full list.
