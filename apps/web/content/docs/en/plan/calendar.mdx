# Use the calendar

The calendar is where you work in Dayopt. Your plans and records sit here. This page covers how to change what you see and how to work with blocks.

## Switching views

You can show three kinds of range.

| View         | Use it to                       | Shortcut     |
| ------------ | ------------------------------- | ------------ |
| **1 day**    | Look at one day in detail       | `Cmd+1`      |
| **2–7 days** | Compare a few days side by side | `Cmd+3` etc. |
| **Week**     | See a whole week at once        | —            |

Pick a view from the switcher in the header. You can show anywhere from 2 to 7 days. Shortcuts cover 3, 5, and 7 days.

| Shortcut | Action      |
| -------- | ----------- |
| `Cmd+1`  | Show 1 day  |
| `Cmd+3`  | Show 3 days |
| `Cmd+5`  | Show 5 days |
| `Cmd+7`  | Show 7 days |

## Moving between dates

| Action         | Result                           |
| -------------- | -------------------------------- |
| `Cmd+←`        | Previous period                  |
| `Cmd+→`        | Next period                      |
| `Cmd+T`        | Back to today                    |
| Swipe sideways | Previous or next period (mobile) |

The step size follows the view you are in. In a 3-day view, you move 3 days at a time.

## Creating a block

Plans and records on the calendar are both called blocks. There are four ways to create one.

| Method        | How                                                    |
| ------------- | ------------------------------------------------------ |
| **Click**     | Click an empty time slot                               |
| **Drag**      | Drag across a time range to set the start and end time |
| **`C`**       | Create a block                                         |
| **`Shift+C`** | Create a 15-minute block at the current time           |

The Inspector opens when the block is created. You can edit the title, date, time, tag, and note.

For details on editing plans, see [Create Plans](/docs/plans).

## Dragging blocks

- **Move** — drag a block to a different time slot
- **Resize** — drag the bottom edge to change the end time

Press `Escape` during a drag to cancel.

## Deleting a block

Select a block and press `Delete` or `Backspace`. You can also right-click a block and delete it from the menu.

## Copy and paste

Press `Cmd+C` to copy a block, then `Cmd+V` where you want it on the calendar. The title, duration, and tag come with it.

## Display settings

View settings change how the calendar looks.

| Setting           | What it does                               |
| ----------------- | ------------------------------------------ |
| Show weekends     | Show or hide Saturday and Sunday (`Cmd+W`) |
| Show week numbers | Show the week number down the left edge    |
| Density           | Compact, default, or spacious              |

Density changes the height of one hour. Use compact on busy days and spacious when you split time into small blocks.

## Searching blocks

Press `Cmd+K` to open search. Find a block by title and jump to its date.

## Keyboard shortcuts

Press `Shift+?` to see every shortcut available right now.

| Shortcut            | Action                             |
| ------------------- | ---------------------------------- |
| `Shift+?`           | Open the shortcut list             |
| `Cmd+←` / `Cmd+→`   | Previous / next period             |
| `Cmd+T`             | Go to today                        |
| `Cmd+1` `3` `5` `7` | Show 1 / 3 / 5 / 7 days            |
| `Cmd+W`             | Show or hide weekends              |
| `Cmd+K`             | Search blocks                      |
| `C`                 | Create a block                     |
| `Shift+C`           | Create a block at the current time |
| `Cmd+C` / `Cmd+V`   | Copy / paste                       |
| `Delete`            | Delete the selected block          |
| `Escape`            | Close the Inspector                |

On Windows and Linux, use `Ctrl` instead of `Cmd`.
