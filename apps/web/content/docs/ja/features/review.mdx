# レビュー

**このページはダミーです。本文は未執筆で、公開もされていません。**

料金ページは無料プランに「Core Review metrics」、Pro に「All Review metrics」と書いています。読者がその約束を確かめられるようにするには、このページが必要です。

## このページに書くこと

- レビューの場所（独立したページではなく、カレンダー横のパネル）
- 差分の数字の意味と、ぴったり一致した時に何も表示しない理由
- 未記録・やらなかった・予定に対する記録・予定外の記録という4つの状態
- 無料で使える指標と、Pro が必要な指標の境界
- 点数・streak・評価ラベルを使わない理由
