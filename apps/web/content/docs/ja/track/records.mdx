# レコードをつける

レコードは「実際に使った時間」の記録です。これからやるつもりの時間であるプランとは別の存在で、カレンダー上でもプランとレコードは別のレーンに表示されます。何かが自動でレコードになることはありません。記録するかどうかは常にあなたが決めます。

## レコードの2つの成り立ち

レコードには、プランに紐づくものと、単独で存在するものがあります。

- **プランに紐づくレコード** — すでにスケジュールしたプランから作成します。紐づきは保持されるため、予定と実際の差分を表示できます
- **プランに紐づかないレコード** — カレンダーに無かった時間をそのまま記録したものです

1つのプランに複数のレコードを紐づけることもできます。たとえば、一度作業を始めて中断し、あとで再開した場合などです。

## プランをレコードに変換する

プランの時間が過ぎても、自動的に記録済みにはなりません。次のいずれかの操作をするまで「未記録の予定」のままです。

| 方法                           | 操作                                                                                         |
| ------------------------------ | -------------------------------------------------------------------------------------------- |
| **ワンタップ「そのまま記録」** | プランカードのボタンをタップすると、プランの時間帯をそのままコピーしたレコードが作成されます |
| **レコードレーンへドラッグ**   | プランカードをレコードレーンへドラッグ。記録したい時間が違う場合はリサイズできます           |
| **「この日を確定」**           | その日の未記録のプランを、1つの操作でまとめてレコードにします                                |

やらなかった場合は、プランを **skip（やらなかった）** にします。Review では「やらなかった」と「未記録」は別の状態として区別されます。

## レコードを直接作成する

プランを経由しなくても、レコードは作成できます。カレンダー上で、すでに終わった時間帯にブロックを作ると、Dayopt は自動的にレコードとして保存します。「予定として保存するか記録として保存するか」を選ぶ操作はありません。ルールはシンプルで、終了時刻が未来ならプラン、現在時刻以前ならレコードになります。時間を調整するたびに、ブロックの表示ラベルも自動で切り替わります。

## プランとレコードを比較する

レコードがプランに紐づいている場合、Dayopt はその差分を数字で添えて表示します。ぴったり一致した場合（±0）は何も表示しません。それは「予定通りだった」というだけのことだからです。プランに紐づかないレコードには差分は表示されません。

過去のプランも、時間・タイトル・アクティビティ・メモを自由に編集できます。編集してもプランのままで、レコードには変わりません。

## レコードを編集する

任意のレコードをクリックすると Inspector が開き、以下を編集できます。

- **タイトル・アクティビティ・メモ** — プランと同じ項目
- **開始・終了時間** — レコードはすでに起きたことの記録なので、自由に訂正できます
