# Google カレンダーと連携する

Google カレンダーを接続すると、その予定がDayoptのカレンダーに薄く表示されます。まだ計画にも実績にもなっていない、参考情報としての表示です。仕事とプライベートの予定を1つの画面で見比べながら、必要なものだけをDayoptに取り込めます。

## 接続する

1. 設定 の 連携 タブを開く
2. Google カレンダー の Google アカウントを接続 をクリック
3. Googleのログイン画面でアカウントを選び、アクセスを許可する
4. 取り込むカレンダーにチェックを入れて 適用 をクリック

Googleの審査が完了するまでの間、ログイン画面で「確認されていないアプリです」という警告が出ることがあります。この場合は 詳細 を開き、Dayoptへの移動を選ぶと接続を続けられます。

## 同期のしくみ

- **読み取り専用**です。DayoptからGoogle カレンダー側を変更することはありません
- 15分ごとに自動で同期します。今すぐ同期 をクリックすると即座に反映されます
- 選択したカレンダーの予定だけが取り込まれます
- 取り込んだ予定のタイトルや時間は編集できません。編集したい場合は、後述の変換を使ってDayoptの計画や実績に変換してください

## 外部の予定を計画・実績に変換する

薄く表示された外部の予定をタップすると、Dayoptの計画または実績に変換されます。

- 終了時刻が未来の予定は、計画になります
- 終了時刻が過去の予定は、実績になります

変換後は取り消せます。表示された通知の「元に戻す」をタップしてください。

不要な予定は、右上に出る非表示アイコンから消せます。確認画面で 非表示 を選ぶと、以後カレンダーに表示されなくなります。

## 複数のアカウントを接続する

Google アカウントを追加 をクリックすると、別のGoogle アカウントも接続できます。仕事用とプライベート用のアカウントを両方接続することもできます。

## 接続を解除する

設定の連携タブで、対象のアカウントの 接続を解除 をクリックします。

- Dayopt内のトークンと接続情報は完全に削除されます
- まだ計画や実績に変換していない外部の予定は消えます
- すでに計画や実績に変換した予定は、そのまま残ります

## トラブルシューティング

### 再接続が必要と表示される

Googleへのアクセスが期限切れになっています。同じGoogle アカウントで 再接続 をクリックしてください。再接続するまで、その接続の同期は止まります。

### カレンダーが同期されない

同期エラーが出ている場合は、しばらく待ってから 今すぐ同期 を試してください。改善しない場合は、一度接続を解除してから接続し直してください。

### 予定が消えた

Dayoptに取り込んでいない外部の予定は、Google カレンダー側で削除・変更されると次の同期で消えます。すでに計画や実績に変換した予定は影響を受けません。
