# タグで分類する

タグは、予定と記録を活動の種類で分類する機能です。DayoptにToDoリストやタスク管理機能はなく、タグが代わりに時間の行き先を示します。

## タグを作る

タグ管理ページ、またはブロックのタグ選択から新しいタグを作れます。

- **階層** — 親タグの下に子タグを1階層だけ作れます（例: 「仕事」の下に「開発」）。3階層目は作れません
- **色** — 10色のパレットから選べます
- **アイコン** — 用途別に選んだ48種類から選べます

## ブロックに付ける

予定と記録には、それぞれ1つのタグしか付けられません。複数のタグを同時に付けることはできません。

## アーカイブする

使わなくなったタグは、削除せずにアーカイブできます。

- アーカイブしたタグは、タグ選択や絞り込みの候補から消えます。新しいブロックには付けられません
- 過去に付けたブロックは、アーカイブ後も元のタグ名と色のまま表示され続けます
- 親タグをアーカイブすると、まだアーカイブしていない子タグも一緒にアーカイブされます

アーカイブしたタグは、あとから復元もできます。

## 削除する

タグを完全に削除すると、関連する予定と記録の件数を示す確認画面が出ます。削除すると、そのタグを付けていたブロックは「タグなし」の未分類として残ります。時間の記録そのものは消えません。

## 無料プランとProプランの違い

無料プランで作れるタグは5個までです。Proプランでは無制限に作れます。
