# タグで分類する

**このページはダミーです。本文は未執筆で、公開もされていません。**

料金ページは無料プランに「Tags」、Pro に「Unlimited tags」と書いています。無料プランの上限が実際にいくつなのかを、このページで示す必要があります。

## このページに書くこと

- コロン区切りの2階層（例: `仕事:開発`）
- 色とアイコンの設定
- 1ブロック1タグであることと、複数タグを持たない理由
- プランとレコードがそれぞれ独立してタグを持つこと
- タグを削除した時に、紐づくブロックがどうなるか
- 無料プランの上限と、Pro で外れるもの
