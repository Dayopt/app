# UIステート・マトリクス — 全組み合わせ棚卸し & ギャップ分析

> **目的**: EntryState × Auth × Plan × Device × Error の5軸を網羅し、未定義の組み合わせを可視化する
> **生成日**: 2026-03-19

---

## 1. 軸レジストリ

| 軸                            | 値                                                          | TypeScript ソース                                                                      |
| ----------------------------- | ----------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **EntryState**                | `upcoming` / `active` / `past`                              | `src/types/entry.ts` — `EntryState`                                                    |
| **EntryStatus** (派生)        | `open` / `closed` (past → closed, else → open)              | `src/features/entry/hooks/useEntryData.ts:126`                                         |
| **Auth**                      | `loading` / `authenticated` / `unauthenticated` / `error`   | `src/stores/useAuthStore.ts`                                                           |
| **Plan (SubscriptionStatus)** | `free` / `active` / `trialing` / `past_due` / `canceled`    | `src/features/settings/server/billing-service.ts`                                      |
| **Device**                    | `mobile` (&lt; 768px + coarse pointer) / `desktop`          | `src/hooks/useIsMobile.ts`                                                             |
| **Error/Network**             | `online-ok` / `online-error` / `offline` / `error-boundary` | `src/shell/providers/OfflineIndicator.tsx`, `src/components/common/error-boundary.tsx` |

**理論上の組み合わせ数**: 3 × 4 × 5 × 2 × 4 = **480通り**
Auth=unauthenticated のとき Entry/Plan は無関係 → 実効 **~330通り**

---

## 2. エリア別マトリクス

凡例:

- **EXPLICIT** — コード上で明示的に分岐・処理されている
- **IMPLICIT** — 暗黙のフォールスルーで動作するが、意図的かどうか不明
- **GAP** — 未定義。潜在バグまたはUX欠陥
