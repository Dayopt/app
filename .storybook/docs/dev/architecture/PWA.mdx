## オフライン同期フロー

<Mermaid chart={`sequenceDiagram
    participant U as ユーザー
    participant App as React App
    participant MC as MutationCache
    participant SQ as Sync Queue (IDB)
    participant SW as Service Worker
    participant API as tRPC API

    Note over U,API: オフライン時
    U->>App: エントリ作成
    App->>MC: mutation実行
    MC-->>MC: networkError発生

    SQ->>SQ: IndexedDBに永続化
    SQ->>SW: Background Sync登録

    Note over U,API: オンライン復帰時
    SW->>SW: sync イベント発火
    SW->>App: SYNC_MUTATION メッセージ
    App->>SQ: deduplicateQueue()
    SQ->>SQ: 同一エンティティのupdate圧縮
    App->>SQ: processQueue()
    SQ->>API: vanillaTrpc.mutate()
    API-->>SQ: 成功
    SQ->>SQ: IndexedDBから削除

`} />

### Mutation圧縮（Deduplication）

同じエンティティへの複数mutationを自動圧縮する:

| パターン                                  | 圧縮結果                         |
| ----------------------------------------- | -------------------------------- |
| `entries.update(A)` → `entries.update(A)` | inputをマージして1件に（後勝ち） |
| `entries.create(A)` → `entries.delete(A)` | 両方削除（net no-op）            |
| `entries.update(A)` → `entries.delete(A)` | deleteのみ残す                   |

## Service Worker キャッシュ戦略

| リクエスト種別     | 戦略          | 詳細                                              |
| ------------------ | ------------- | ------------------------------------------------- |
| **ナビゲーション** | Network First | 失敗時はキャッシュ → `/offline` ページ            |
| **静的アセット**   | Cache First   | JS/CSS/画像/フォント → ネットワークフォールバック |
| **動的リクエスト** | Network First | GETのみキャッシュ → キャッシュフォールバック      |
| **除外**           | No Cache      | HMR、認証API、tRPC API                            |

```
// キャッシュバージョニング
CACHE_VERSION = '2'
dayopt-static-v2  → 静的アセット（長期）
dayopt-dynamic-v2 → 動的レスポンス（短期）
```

## TanStack Query キャッシュ永続化

タブを閉じて再度開いた際にキャッシュデータをIndexedDBから即座に復元する。

```typescript
// src/shell/providers.tsx
<PersistQueryClientProvider
  client={queryClient}
  persistOptions={{
    persister: queryPersister,    // IndexedDB (superjsonシリアライズ)
    maxAge: 2 * 60 * 60 * 1000,  // 2時間
    buster: CACHE_BUSTER,        // デプロイ毎にキャッシュ破棄
    dehydrateOptions: {
      shouldDehydrateQuery: (q) => q.state.status === 'success',
      shouldDehydrateMutation: () => false, // mutation はsync queueで管理
    },
  }}
>
```

| 設定               | 値          | 理由                                 |
| ------------------ | ----------- | ------------------------------------ |
| **maxAge**         | 2時間       | staticCache の gcTime に合わせる     |
| **buster**         | APP_VERSION | デプロイ時に古いキャッシュを自動破棄 |
| **シリアライザー** | superjson   | tRPCと同じ（Date型のround-trip保証） |

## Zustand Storage Adapter

全6ストアが `platformStorage()` を使用。React Native移行時は `setPlatformStorageBackend()` で `AsyncStorage` を注入するだけ。

```typescript
// Web（現行）
import { platformStorage } from '@/lib/zustand/storage';

persist(storeCreator, {
  name: 'calendar-settings',
  storage: platformStorage(), // localStorage ベース
});

// React Native（将来）
import AsyncStorage from '@react-native-async-storage/async-storage';
setPlatformStorageBackend({
  getItem: (name) => AsyncStorage.getItem(name),
  setItem: (name, value) => AsyncStorage.setItem(name, value),
  removeItem: (name) => AsyncStorage.removeItem(name),
});
```

対象ストア: `useLayoutStore` / `useCalendarSettingsStore` / `useCalendarFilterStore` / `useCalendarScrollStore` / `useTourStore` / `createFilterStore`

## iOS Safari 固有対応

| 問題                         | 対策                                            | ファイル                     |
| ---------------------------- | ----------------------------------------------- | ---------------------------- |
| SWキャッシュ7日失効          | 定期的にSW ping（3日ごと + visibilitychange時） | `startSWKeepAlive()`         |
| `100vh` バグ                 | `--vh` CSS変数で実際のビューポート高さを設定    | `fixIOSViewportHeight()`     |
| スワイプバック離脱           | history sentinel エントリで popstate をガード   | `preventStandaloneNavLoss()` |
| 外部リンクでSafariに遷移     | click ハンドラで `window.open` に差替え         | `patchExternalLinks()`       |
| `beforeinstallprompt` 非対応 | iOS専用「共有→ホーム画面に追加」ガイドUI        | `IOSInstallGuide`            |
| スプラッシュスクリーン       | 8デバイスサイズの `apple-touch-startup-image`   | `layout.tsx`                 |

## インストール促進

### Android / Chrome系

`beforeinstallprompt` イベントをキャプチャし、カスタム `InstallBanner` を表示。
dismissすると7日間非表示（localStorage）。

### iOS Safari

`IOSInstallGuide` コンポーネントで「共有→ホーム画面に追加」の手順を表示。
standalone mode 検知済みの場合は非表示。
