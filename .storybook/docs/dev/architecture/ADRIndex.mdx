## ADRの追加方法

1. `docs/adr/` に `ADR-NNN-slug.md` を作成
2. `src/stories/docs/architecture/` に対応する `.mdx` を作成
3. テンプレート: Context → Decision → Detail → Consequences
4. 本文は日本語、ファイル名は英語
