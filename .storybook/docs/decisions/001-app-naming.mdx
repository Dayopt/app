# アプリ名決定: Dayopt

## 基本情報

- **決定日**: 2025-01-05
- **決定者**: 創業者
- **ステータス**: 完了
- **カテゴリ**: ブランド

## 決定事項

### 概要

アプリ名を「Dayopt」、ドメインを「dayopt.app」に決定。

### 決定内容

- **アプリ名**: Dayopt（デイオプト）
- **ドメイン**: dayopt.app
- **取得先**: Vercel Domains
- **価格**: $15/年

## 背景・理由

### 課題・ニーズ

- 仮名「BoxLog」から正式名への移行が必要
- 時間管理アプリとして認知されつつ、差別化を表現したい
- グローバル展開も視野に入れた英語名

### 名前に込めた意味

| 要素    | 意味                     |
| ------- | ------------------------ |
| **day** | 一日を対象とする         |
| **opt** | 選ぶ（選択型ログ）       |
| **opt** | optimize（最適化）の暗示 |

### コンセプトとの整合性

- 「選択型ログ」→ opt（選ぶ）
- 「一日を最適化」→ day + optimize
- 予定とログ両方カバー → 「一日を選ぶ」

## 検討内容

### 検討した選択肢

#### 却下した候補

| 候補              | 却下理由                                  |
| ----------------- | ----------------------------------------- |
| DayPick           | 写真アプリ（DayPix, Day Pic）と混同リスク |
| Timepick          | 同名アプリが既に存在                      |
| Optimo            | フィットネスアプリが既に存在              |
| Optime            | 時間割アプリが既に存在                    |
| Nowpick           | 「pick」が購入連想、ログ感が弱い          |
| Kairos, Cadence等 | 抽象的すぎてアプリが何かわからない        |

#### Dayoptを採用した理由

- App Store / Google Play に同名アプリなし
- dayopt.app ドメインが $15 で取得可能
- 「選択」と「最適化」のダブルミーニング
- 英語として自然、グローバル対応可能
- 6文字でシンプル、覚えやすい
- 購入連想がない（pickと違い）

### 懸念点と対策

| 懸念                          | 対策                       |
| ----------------------------- | -------------------------- |
| 「opt」が日本人に馴染みにくい | UI/コピーで補完            |
| Day系アプリが多い             | ブランド体験で差別化       |
| 硬い印象                      | 柔らかいロゴ・キャラで補完 |
| 生産性ツールと誤解            | 「納得感」をコピーで訴求   |

## リスク・対策

### 予想されるリスク

1. **DayOptics社との混同**: 業界が全く異なる（光学部品 vs 時間管理アプリ）ため低リスク
2. **dayopt.comが取れない**: .appで十分。アプリビジネスには適切

### ロールバック計画

- $15で試せるため、不都合があれば別ドメインに移行可能
- リリース前であれば名前変更も可能
