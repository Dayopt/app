# Cookie同意バナー不要の決定

## 基本情報

- **決定日**: 2026-02-16
- **決定者**: 創業者
- **ステータス**: 撤回（[2026-02-18 Cookie同意バナー導入の決定](?path=/docs/decisions-008-cookie-consent-required--docs) により変更）
- **カテゴリ**: 技術/プロダクト

## 決定事項

### 概要

GA4等のマーケティング用トラッキングを使用しないため、Cookie同意バナーは表示しない。外部送信規則への対応はプライバシーポリシーへの記載で行う。

### 決定内容

- Cookie同意バナーは**表示しない**
- プライバシーポリシーに外部送信先（Supabase, Vercel Analytics, Sentry）を**明記する**
- GA4等のマーケティング用トラッキングは**導入しない**（現段階）
- 計測はVercel Analyticsのカスタムイベント（cookie-less）で行う

## 背景・理由

### 課題・ニーズ

- Cookie同意バナーが本当に必要か疑問が生じた
- GA4を使わないのにバナーを表示する意味があるのか確認が必要だった

### データ・根拠

#### 使用ツールの分類

| ツール           | Cookie使用 | 分類                      | 同意バナー | 外部送信規則 |
| ---------------- | ---------- | ------------------------- | ---------- | ------------ |
| Supabase Auth    | あり       | 必須（認証セッション）    | 不要       | PP記載で対応 |
| Vercel Analytics | なし       | cookie-less設計           | 不要       | PP記載で対応 |
| Sentry           | あり       | 必須/機能的（エラー監視） | 不要       | PP記載で対応 |

#### Vercel Analyticsで十分な理由

- PV・訪問者数・リファラーは自動取得可能
- ボタンクリック等はカスタムイベント（`track()`）で計測可能
- 広告を出していないため広告連携は不要
- コホート分析が必要になるのはユーザー数が増えてから
- GA4は後から追加が容易（その時にバナーも追加すればよい）

#### 法的根拠

- **GDPR/個人情報保護法**: 必須Cookie（Strictly Necessary）はユーザー同意なしで使用可能
- **外部送信規則**（電気通信事業法、2023年6月施行）: 外部送信先の「公表」（プライバシーポリシーへの記載）で対応可能。同意バナーは不要
- **GAFA実例**: Apple.comも必須cookieのみのページではバナーを出さず、プライバシーポリシーに記載するのみ

## 検討内容

### 検討した選択肢

#### 選択肢A: Cookie同意バナーを表示する

- **内容**: 現状のまま同意バナーを表示し続ける
- **メリット**: 法的リスクをゼロにできる
- **デメリット**: 不要なバナーがUXを損なう、必須cookieしか使っていないのにバナーは過剰
- **リスク**: 低

#### 選択肢B: Cookie同意バナーを外す（採用）

- **内容**: バナーを外し、プライバシーポリシーに外部送信先を明記する
- **メリット**: クリーンなUX、不要な要素を排除
- **デメリット**: 将来GA4等を導入時にバナー追加が必要
- **リスク**: 低（法的要件は満たしている）

### 採用理由

- 使用ツールがすべて「必須cookie」または「cookie不使用」であり、法的に同意バナーは不要
- 不要なバナーはUXを損なう
- GAFA-First原則に沿った判断

### 却下理由

- 選択肢A: 法的に不要なバナーを表示し続けることはUXの観点で不適切

## 影響範囲

### 関連システム・プロセス

- **変更が必要な箇所**:
  - appリポジトリ: Cookie同意バナーコンポーネントの削除
  - プライバシーポリシー: 外部送信先（Supabase, Vercel Analytics, Sentry）の明記
- **影響を受ける機能**: Cookie同意フロー

## 実装計画

- [ ] Cookie同意バナーコンポーネントの削除（appリポジトリ）

## リスク・対策

### 予想されるリスク

1. **GA4導入時の対応漏れ**: 再検討条件をこの決定記録に明記しておく
2. **海外展開時のGDPR対応**: 海外展開を検討する際に再評価

### 再検討条件

- GA4や広告トラッキング（Meta Pixel等）を導入する場合 → バナー追加が必要
- 海外展開（特にEU圏）を検討する場合 → GDPR対応の再検討が必要
