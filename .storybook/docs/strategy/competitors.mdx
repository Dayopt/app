# 競合分析

Dayoptの競合サービスと差別化ポイントを整理。

---

## 競合カテゴリ

### 直接競合（時間記録・タイムトラッキング）

| サービス     | 特徴                   | ターゲット           | 価格帯       |
| ------------ | ---------------------- | -------------------- | ------------ |
| Toggl Track  | シンプルな時間記録     | フリーランス・チーム | 無料〜$18/月 |
| Clockify     | 無料の時間トラッキング | 個人・チーム         | 無料〜$12/月 |
| RescueTime   | 自動トラッキング       | 生産性向上したい人   | 無料〜$12/月 |
| Timing (Mac) | 自動記録・Mac専用      | Mac開発者            | $8〜$14/月   |

### 間接競合（タスク管理・習慣化）

| サービス | 特徴                         | ターゲット      |
| -------- | ---------------------------- | --------------- |
| Todoist  | タスク管理                   | 個人・チーム    |
| Notion   | オールインワンワークスペース | 個人・チーム    |
| Habitify | 習慣トラッキング             | 習慣化したい人  |
| Streaks  | 習慣継続                     | iOS/Macユーザー |

## Dayoptの差別化

### ポジショニング

```
            完了型（タスク）
                ↑
                |
    Todoist  ●  |
                |
←────────────────────────────→
  生産性重視     |    納得感重視
                |
    Toggl   ●   |  ● Dayopt
                |
                ↓
            選択型（ログ）
```

### 差別化軸

| 観点           | 競合           | Dayopt           |
| -------------- | -------------- | ---------------- |
| 記録の目的     | 生産性・効率化 | 納得感・自己理解 |
| 操作感         | 機能が多い     | シンプル・最小限 |
| 時間の捉え方   | 「使った」時間 | 「選んだ」時間   |
| フィードバック | 統計・レポート | 振り返り・気づき |

### 競合にない価値

1. **「選んだ」という主体性**
   - 他ツール：時間を「計測」する
   - Dayopt：時間を「選ぶ」体験

2. **納得感の醸成**
   - 他ツール：生産性を上げることがゴール
   - Dayopt：「今日も充実していた」と感じることがゴール

3. **シンプルさ**
   - 他ツール：多機能・チーム向け機能
   - Dayopt：個人向け・必要最低限

## 競合の強み・弱み

### Toggl Track

**強み**

- 知名度・実績
- チーム向け機能が充実
- 連携ツールが豊富

**弱み**

- 多機能で複雑になりがち
- 「計測」感が強い

### RescueTime

**強み**

- 自動トラッキング
- 生産性スコア

**弱み**

- 自動記録は受動的
- 「監視されている」感

### Notion

**強み**

- オールインワン
- カスタマイズ自由

**弱み**

- 時間記録に特化していない
- 設定が複雑

## 学ぶべきこと

### UI/UX

- Toggl: ワンクリックで記録開始のシンプルさ
- Notion: 柔軟なビュー切り替え

### マーケティング

- Toggl: 明確なターゲット（フリーランス）
- RescueTime: 「生産性向上」という明確な価値訴求

### 価格戦略

- Clockify: 無料でも十分使える→有料で追加価値
- Toggl: 無料→Pro→Businessの段階
